
# Практична робота №2

## Тема
Порти й регістри вводу/виводу.

## Мета роботи
Навчитися працювати з портами та регістрами вводу/виводу мікроконтролера, вивчити їх функції та призначення.

## Завдання

1. Вивчити призначення регістрів TRISA, TRISB, PORTA, PORTB.
2. Написати програму для роботи з портами мікроконтролера PIC16F84A відповідно до схеми та алгоритму.
3. Налаштувати порт A на введення інформації за допомогою регістра TRISA.
4. Налаштувати порт B на виведення інформації за допомогою регістра TRISB.
5. Організувати опитування стану кнопок K1 та K2.
6. Забезпечити виведення відповідних сигналів через PORTB.
7. Перевірити роботу програми у середовищі MPLAB X IDE.

## Використані засоби

- Мікроконтролер PIC16F84A.
- MPLAB X IDE v6.35.
- Компілятор MPLAB XC8 v3.10.
- Мова програмування C.
- MPLAB Simulator.
- Proteus 8 Professional для моделювання електричної схеми.

## Теоретичні відомості

Мікроконтролер PIC16F84A має два порти вводу/виводу: PORTA та PORTB.

PORTA — 5-розрядний порт, який містить виводи RA0–RA4.

PORTB — 8-розрядний порт, який містить виводи RB0–RB7.

Для керування напрямком роботи портів використовуються регістри TRISA та TRISB.

Якщо біт регістра TRIS дорівнює 1, відповідний вивід налаштований на введення інформації.

Якщо біт регістра TRIS дорівнює 0, відповідний вивід налаштований на виведення інформації.

Регістри PORTA та PORTB використовуються для зчитування вхідних сигналів і встановлення логічних рівнів на виходах мікроконтролера.


## Хід виконання роботи

### 1. Ознайомлення з портами мікроконтролера

У ході практичної роботи було розглянуто особливості використання портів вводу/виводу мікроконтролера PIC16F84A.

Мікроконтролер має два порти:
- PORTA — 5-розрядний порт вводу/виводу.
- PORTB — 8-розрядний порт вводу/виводу.

Для налаштування напрямку роботи портів використовуються регістри TRISA та TRISB.

Значення біта 1 відповідає режиму введення інформації, а значення 0 — режиму виведення.

### 2. Налаштування портів

Для реалізації завдання було обрано такі налаштування:

```c
TRISA = 0x1F;
TRISB = 0x00;
PORTB = 0x00;
```

Команда TRISA = 0x1F налаштовує всі п'ять виводів порту A на введення.

Команда TRISB = 0x00 налаштовує всі вісім виводів порту B на виведення.

Команда PORTB = 0x00 встановлює початковий стан виходів порту B.

### 3. Реалізація алгоритму

Було розроблено програму мовою C, яка реалізує керування світлодіодами за допомогою двох кнопок K1 та K2.

Кнопку K1 підключено до RA0, кнопку K2 — до RA1.

Алгоритм роботи:

1. Ініціалізація портів мікроконтролера.
2. Перевірка стану кнопки K1.
3. Перевірка стану кнопки K2.
4. Вибір відповідного значення для PORTB.
5. Виведення сигналів на світлодіоди.
6. Повторення робочого циклу.

Для перевірки стану кнопок використовується оператор if.

Для безперервного виконання програми застосовується цикл while(1).

### 4. Таблиця станів кнопок

| K1 | K2 | Дія | Значення PORTB |
|---|---|---|---|
| Не натиснута | Не натиснута | Усі виходи в логічній 1 | 0xFF |
| Не натиснута | Натиснута | Вивести число 129 | 0x81 |
| Натиснута | Не натиснута | Вивести число 0x3C | 0x3C |
| Натиснута | Натиснута | Встановити RB1 = 1 | Залежить від попереднього стану |

У випадку одночасного натискання двох кнопок змінюється лише біт RB1, тому значення інших бітів PORTB зберігаються.

### 5. Очікувані результати

При відсутності натискання кнопок на PORTB виводиться 0xFF (11111111), тому всі вісім світлодіодів повинні світитися за умови підключення до GND через резистори.

При натисканні лише кнопки K2 на PORTB виводиться 129 (10000001). Світяться світлодіоди RB7 та RB0.

При натисканні лише кнопки K1 на PORTB виводиться 0x3C (00111100). Світяться світлодіоди RB5, RB4, RB3 та RB2.

При одночасному натисканні кнопок встановлюється RB1 = 1, а решта бітів зберігають попередні значення.

### 6. Перевірка роботи програми

Для перевірки програми передбачено використання MPLAB X IDE та Proteus 8 Professional.

Послідовність перевірки:

1. Створити проєкт для PIC16F84A.
2. Додати файл main.c.
3. Виконати компіляцію за допомогою XC8.
4. Запустити моделювання схеми у Proteus.
5. Перевірити всі чотири комбінації станів кнопок.
6. Порівняти стан світлодіодів з очікуваними результатами.

## Контрольні запитання

### 1. Яке призначення і функціональні особливості портів PIC16F84A?

Порти мікроконтролера PIC16F84A призначені для обміну інформацією із зовнішніми пристроями.

Мікроконтролер має два порти:
- PORTA — 5-розрядний порт із виводами RA0–RA4.
- PORTB — 8-розрядний порт із виводами RB0–RB7.

Кожен вивід можна налаштувати окремо на введення або виведення інформації.

Порт A не має внутрішніх підтягувальних резисторів, а порт B підтримує програмно керовані внутрішні підтягувальні резистори.

Виводи RB4–RB7 можуть формувати переривання при зміні логічного рівня.

### 2. Як налаштувати порти для отримання та на виведення інформації?

Для налаштування напрямку роботи портів використовуються регістри TRISA та TRISB.

Якщо відповідний біт регістра TRIS дорівнює 1, вивід працює на введення інформації.

Якщо біт дорівнює 0, вивід працює на виведення інформації.

Приклад:

```c
TRISA = 0x1F; // Усі виводи PORTA на введення
TRISB = 0x00; // Усі виводи PORTB на виведення
```

Для читання інформації використовується регістр PORTA або PORTB, а для встановлення вихідних сигналів — запис значення у відповідний регістр порту.

### 3. Як відбувається процес модифікації біта порта?

Модифікація біта порту відбувається за принципом «читання — модифікація — запис».

Спочатку зчитується поточний стан порту, потім змінюється необхідний біт, після чого результат записується назад у регістр.

В асемблері для цього використовуються команди BSF та BCF.

Приклад мовою C:

```c
PORTBbits.RB1 = 1;
```

Ця команда встановлює біт RB1 у логічну одиницю.

Під час роботи з портами потрібно враховувати, що операції читання-модифікації-запису можуть залежати від фактичних логічних рівнів на виводах.

### 4. Як підключити до мікроконтролера світлодіод?

Світлодіод можна підключити до мікроконтролера двома способами:

1. Між виходом порту та GND.
2. Між джерелом живлення Vcc та виходом порту.

У першому випадку світлодіод світиться при встановленні логічної 1 на виході.

У другому випадку світлодіод світиться при встановленні логічного 0.

Світлодіод необхідно підключати послідовно зі струмообмежувальним резистором.

### 5. Для чого у схемі підключення світлодіодів до мікроконтролера використовуються обмежуючі резистори?

Струмообмежувальні резистори використовуються для обмеження струму, який проходить через світлодіод.

Без резистора струм може перевищити допустиме значення, що призведе до пошкодження світлодіода або виходу мікроконтролера.

Резистор забезпечує безпечну роботу електричного кола та захищає його компоненти.

### 6. Для чого використовуються незалежні модулі?

Незалежні модулі використовуються для поділу програми на окремі функціональні частини.

Вони дозволяють:

- Покращити структуру програмного коду.
- Спростити тестування та відлагодження.
- Повторно використовувати функції в інших проєктах.
- Полегшити супровід і розширення програми.

Зазвичай модуль складається з двох файлів: заголовного файлу з розширенням .h та файлу реалізації з розширенням .c.

### 7. Як здійснюється підключення сторонніх модулів до проєкту?

Для підключення стороннього модуля необхідно додати його файли .c та .h до проєкту.

У програмному файлі, який використовує функції модуля, потрібно підключити відповідний заголовний файл за допомогою директиви #include.

Приклад:

```c
#include "new_module.h"
```

У заголовному файлі розміщуються оголошення функцій, констант і типів даних.

У файлі .c міститься реалізація функцій.

Для запобігання повторному підключенню заголовного файлу використовуються директиви #ifndef, #define та #endif.
