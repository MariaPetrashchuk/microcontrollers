
# Практична робота №4

## Тема
Система переривань мікроконтролера.

## Мета роботи
Вивчити систему переривань мікроконтролера PIC16F84A, способи формування переривань, використання обробників декількох переривань.

## Завдання

1. Написати програму обробки переривань за ознаками роботи модуля TMR0.
2. Налаштувати TMR0 у режимі таймера з попереднім дільником 1:64 при Fosc = 4 МГц.
3. Виконати ініціалізацію портів, таймера та системи переривань.
4. Реалізувати нескінченний цикл, у якому світлодіод на RA1 вмикається та вимикається з інтервалом 0,5 с.
5. Створити обробник переривань TMR0 для динамічної індикації дворозрядного числа.
6. Визначити максимальний час виконання обробника переривання в машинних циклах та одиницях часу.

## Використане обладнання та програмне забезпечення

- Мікроконтролер PIC16F84A.
- MPLAB X IDE v6.35.
- Компілятор MPLAB XC8 v3.10.
- Proteus 8 Professional.
- Світлодіод.
- Дворозрядний семисегментний індикатор.
- Мова програмування C.

## Теоретичні відомості

### Система переривань

Переривання — це механізм, який дозволяє мікроконтролеру тимчасово призупиняти виконання основної програми для обробки певної події.

Після завершення обробника переривання мікроконтролер повертається до виконання основної програми.

### Регістр INTCON

Регістр INTCON використовується для керування перериваннями.

Основні біти:

- GIE — глобальний дозвіл переривань.
- T0IE — дозвіл переривань від переповнення TMR0.
- T0IF — прапорець переповнення TMR0.
- INTE — дозвіл зовнішнього переривання.
- INTF — прапорець зовнішнього переривання.
- RBIE — дозвіл переривання при зміні сигналів RB4–RB7.
- RBIF — прапорець зміни сигналів RB4–RB7.

### Переривання від TMR0

TMR0 — восьмибітний таймер мікроконтролера PIC16F84A.

При переповненні таймера встановлюється прапорець T0IF.

Якщо встановлені біти T0IE та GIE, мікроконтролер переходить до виконання обробника переривання.

Після обробки прапорець T0IF необхідно скинути програмно.


## Хід виконання роботи

### Завдання 1. Розрахунок параметрів таймера TMR0

Відповідно до завдання практичної роботи було розраховано параметри таймера TMR0 мікроконтролера PIC16F84A.

Вихідні дані:
- Тактова частота Fosc = 4 МГц.
- Розрядність таймера — 8 біт.
- Попередній дільник — 1:64.
- Джерело тактування — внутрішній генератор.

Тривалість машинного циклу:

Tcy = 4 / 4 000 000 = 1 мкс.

Період збільшення таймера:

Ttmr0 = 1 × 64 = 64 мкс.

Час повного переповнення таймера:

Toverflow = 256 × 64 = 16384 мкс = 16,384 мс.

Для формування інтервалу перемикання розрядів приблизно 10 мс було визначено початкове значення таймера:

N = 10000 / 64 = 156,25.

TMR0 = 256 - 156 = 100.

Розрахунковий час до переповнення:

T = 156 × 64 = 9984 мкс = 9,984 мс.

Для налаштування таймера використовується регістр OPTION_REG зі значенням 0x85.

Для дозволу переривань використовуються біти T0IE та GIE регістра INTCON.

Після переповнення TMR0 встановлюється прапорець T0IF, що викликає виконання обробника переривання.


### Завдання 2. Розробка програми обробки переривань TMR0

Було розроблено програму для мікроконтролера PIC16F84A, яка використовує систему переривань від переповнення таймера TMR0.

Тактова частота мікроконтролера становить 4 МГц.

Для таймера TMR0 встановлено попередній дільник 1:64.

Початкове значення таймера — 100.

У головній програмі реалізовано блимання світлодіода, підключеного до виводу RA1.

Світлодіод вмикається на 0,5 секунди, після чого вимикається на 0,5 секунди. Повний цикл блимання становить приблизно 1 секунду.

В обробнику переривань реалізовано динамічну індикацію числа 03.

Для керування сегментами використовується PORTB, а для вибору активного розряду — RA2 та RA3.

Під час кожного переривання виконується перемикання активного розряду та виведення відповідного коду цифри.

Розрахунковий інтервал перемикання розрядів становить приблизно 10 мс.

Завдяки використанню переривань керування індикатором виконується незалежно від основного циклу блимання світлодіода.



### Завдання 3. Налагодження системи переривань

Для налагодження програми використовується MPLAB X IDE v6.35 з компілятором XC8 v3.10 та вбудованим симулятором.

Програма передбачає використання переривань від переповнення таймера TMR0.

Під час налагодження необхідно перевірити:
- Збільшення значення регістра TMR0.
- Встановлення прапорця T0IF при переповненні.
- Перехід до обробника ISR.
- Повторне завантаження TMR0.
- Скидання прапорця T0IF.
- Перемикання розрядів семисегментного індикатора.
- Повернення до основної програми після обробки переривання.

### Визначення часу обробки переривання

Тактова частота мікроконтролера:

Fosc = 4 МГц.

Тривалість машинного циклу:

Tcy = 4 / Fosc = 1 мкс.

Час виконання обробника визначається за формулою:

T_ISR = N_cycles × Tcy.


Вимірювання виконується для обох гілок обробника переривання. За максимальний час приймається більше з отриманих значень.

### Завдання 4. Моделювання пристрою в Proteus

Для перевірки програми передбачено моделювання електричної схеми в середовищі Proteus 8 Professional.

Схема складається з мікроконтролера PIC16F84A, дворозрядного семисегментного індикатора, світлодіода, двох транзисторів NPN та струмообмежувальних резисторів.

Для керування сегментами індикатора використовується порт PORTB.

Для вибору активного розряду використовуються виводи RA2 та RA3.

Світлодіод підключений до виводу RA1.

Тактова частота мікроконтролера становить 4 МГц.

Програма використовує переривання від переповнення таймера TMR0 з попереднім дільником 1:64.

Очікувані результати моделювання:

1. Відображення числа 03 на дворозрядному індикаторі.
2. Перемикання розрядів приблизно кожні 10 мс.
3. Вмикання та вимикання світлодіода з інтервалом 0,5 с.
4. Незалежне виконання основної програми та обробника переривань.

## Контрольні запитання

### 1. Скільки джерел переривань мають мікроконтролери PICmicro середнього сімейства?

Мікроконтролери PICmicro середнього сімейства можуть мати декілька джерел переривань залежно від конкретної моделі та набору периферійних модулів.

У методичних вказівках наведено 15 можливих джерел переривань, серед яких:

- Зовнішнє переривання INT.
- Переповнення таймера TMR0.
- Зміна рівня сигналів на входах RB4–RB7.
- Переривання від таймерів TMR1 і TMR2.
- Завершення перетворення АЦП.
- Переривання від USART.
- Завершення запису в EEPROM.
- Переривання від інших периферійних модулів.

Безпосередньо мікроконтролер PIC16F84A підтримує чотири джерела переривань: зовнішнє INT, переповнення TMR0, зміну стану RB4–RB7 та завершення запису в EEPROM.

### 2. Який регістр керує перериваннями?

Основним регістром керування перериваннями мікроконтролера PIC16F84A є INTCON.

Він містить біти дозволу переривань та прапорці, які вказують на виникнення відповідних подій.

Основні біти регістра INTCON:

- GIE — глобальний дозвіл переривань.
- T0IE — дозвіл переривань від таймера TMR0.
- INTE — дозвіл зовнішнього переривання.
- RBIE — дозвіл переривань при зміні сигналів RB4–RB7.
- T0IF — прапорець переповнення TMR0.
- INTF — прапорець зовнішнього переривання.
- RBIF — прапорець зміни сигналів RB4–RB7.

Для роботи переривань від TMR0 необхідно встановити біти GIE та T0IE.

### 3. По відношенню до МК, якого типу є переривання?

За походженням переривання поділяються на внутрішні та зовнішні.

Внутрішні переривання виникають унаслідок подій усередині мікроконтролера, наприклад переповнення таймера TMR0 або завершення запису в EEPROM.

Зовнішні переривання виникають унаслідок зміни електричних сигналів на відповідних виводах мікроконтролера.

Прикладом зовнішнього переривання є сигнал на вході RB0/INT.

У практичній роботі використовується внутрішнє переривання від переповнення таймера TMR0.

### 4. Для чого використовується стек?

Стек використовується для тимчасового збереження адрес повернення під час виклику підпрограм та обробки переривань.

Коли виникає дозволене переривання, мікроконтролер зберігає адресу повернення у стеку та переходить до виконання обробника за адресою 0004h.

Після завершення обробника команда RETFIE відновлює адресу повернення зі стеку та дозволяє продовжити виконання основної програми.

Таким чином, стек забезпечує правильне повернення до перерваної ділянки програми.

### 5. Як при переході до підпрограми обробки переривання зберегти значення регістрів W, STATUS?

Під час переходу до обробника переривання необхідно зберегти контекст виконання основної програми.

Для цього значення регістрів W та STATUS записуються в тимчасові комірки оперативної пам'яті.

Послідовність дій:

1. Зберегти значення робочого регістра W.
2. Зберегти значення регістра STATUS.
3. Виконати команди обробника переривання.
4. Відновити значення STATUS.
5. Відновити значення W.
6. Повернутися до основної програми командою RETFIE.

При програмуванні мовою C з використанням компілятора XC8 необхідне збереження та відновлення контексту обробника переривання зазвичай забезпечує компілятор.

## Висновок

Під час виконання практичної роботи №4 було вивчено принципи функціонування системи переривань мікроконтролера PIC16F84A та особливості використання таймера TMR0 для формування періодичних переривань.

Розглянуто призначення регістра INTCON, механізм встановлення та скидання прапорців переривань, використання глобального дозволу переривань GIE та індивідуального дозволу T0IE.

Для таймера TMR0 було обрано внутрішнє джерело тактування з частотою Fosc = 4 МГц і попередній дільник 1:64.

Розраховано тривалість машинного циклу, яка становить 1 мкс, та період збільшення таймера — 64 мкс.

Розроблено програму мовою C, у якій головний цикл забезпечує вмикання та вимикання світлодіода на виводі RA1 з інтервалом 0,5 секунди.

Для обробки переповнення TMR0 створено обробник переривань, що забезпечує почергове перемикання розрядів семисегментного індикатора для відображення числа 03.

Також розглянуто порядок збереження контексту виконання програми під час переходу до обробника переривання та повернення до основної програми.

Отже, у процесі практичної роботи було закріплено знання про налаштування апаратних переривань, використання таймерів та організацію одночасного виконання декількох завдань у мікроконтролерних системах.
