
# Практична робота №4

## Тема
Система переривань мікроконтролера.

## Мета роботи
Вивчити систему переривань мікроконтролера PIC16F84A, способи формування переривань, використання обробників декількох переривань.

## Завдання

1. Написати програму обробки переривань за ознаками роботи модуля TMR0.
2. Налаштувати TMR0 у режимі таймера з попереднім дільником 1:64 при Fosc = 4 МГц.
3. Виконати ініціалізацію портів, таймера та системи переривань.
4. Реалізувати нескінченний цикл, у якому світлодіод на RA1 вмикається та вимикається з інтервалом 0,5 с.
5. Створити обробник переривань TMR0 для динамічної індикації дворозрядного числа.
6. Визначити максимальний час виконання обробника переривання в машинних циклах та одиницях часу.

## Використане обладнання та програмне забезпечення

- Мікроконтролер PIC16F84A.
- MPLAB X IDE v6.35.
- Компілятор MPLAB XC8 v3.10.
- Proteus 8 Professional.
- Світлодіод.
- Дворозрядний семисегментний індикатор.
- Мова програмування C.

## Теоретичні відомості

### Система переривань

Переривання — це механізм, який дозволяє мікроконтролеру тимчасово призупиняти виконання основної програми для обробки певної події.

Після завершення обробника переривання мікроконтролер повертається до виконання основної програми.

### Регістр INTCON

Регістр INTCON використовується для керування перериваннями.

Основні біти:

- GIE — глобальний дозвіл переривань.
- T0IE — дозвіл переривань від переповнення TMR0.
- T0IF — прапорець переповнення TMR0.
- INTE — дозвіл зовнішнього переривання.
- INTF — прапорець зовнішнього переривання.
- RBIE — дозвіл переривання при зміні сигналів RB4–RB7.
- RBIF — прапорець зміни сигналів RB4–RB7.

### Переривання від TMR0

TMR0 — восьмибітний таймер мікроконтролера PIC16F84A.

При переповненні таймера встановлюється прапорець T0IF.

Якщо встановлені біти T0IE та GIE, мікроконтролер переходить до виконання обробника переривання.

Після обробки прапорець T0IF необхідно скинути програмно.


## Хід виконання роботи

### Завдання 1. Розрахунок параметрів таймера TMR0

Відповідно до завдання практичної роботи було розраховано параметри таймера TMR0 мікроконтролера PIC16F84A.

Вихідні дані:
- Тактова частота Fosc = 4 МГц.
- Розрядність таймера — 8 біт.
- Попередній дільник — 1:64.
- Джерело тактування — внутрішній генератор.

Тривалість машинного циклу:

Tcy = 4 / 4 000 000 = 1 мкс.

Період збільшення таймера:

Ttmr0 = 1 × 64 = 64 мкс.

Час повного переповнення таймера:

Toverflow = 256 × 64 = 16384 мкс = 16,384 мс.

Для формування інтервалу перемикання розрядів приблизно 10 мс було визначено початкове значення таймера:

N = 10000 / 64 = 156,25.

TMR0 = 256 - 156 = 100.

Розрахунковий час до переповнення:

T = 156 × 64 = 9984 мкс = 9,984 мс.

Для налаштування таймера використовується регістр OPTION_REG зі значенням 0x85.

Для дозволу переривань використовуються біти T0IE та GIE регістра INTCON.

Після переповнення TMR0 встановлюється прапорець T0IF, що викликає виконання обробника переривання.
