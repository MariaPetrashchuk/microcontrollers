# Практична робота №5

**Тема:** Керування алфавітно-символьним РКІ.

**Дисципліна:** Мікроконтролери та їх програмування  
**Виконала:** Петращук Марія  
**Мікроконтролер:** PIC16F877A  
**Індикатор:** LCD LM016L (16×2)  
**Середовище розробки:** MPLAB X IDE v6.35, XC8  
**Середовище моделювання:** Proteus 8 Professional

## 1. Мета роботи

Навчитися керувати алфавітно-символьним рідкокристалічним індикатором за допомогою мікроконтролера PIC16F877A, освоїти принципи передавання команд і символів на LCD та реалізувати програму для відображення текстової інформації.

## 2. Завдання роботи

1. Ознайомитися з принципами роботи алфавітно-символьного LCD.
2. Створити проєкт для PIC16F877A з тактовою частотою 4 МГц.
3. Реалізувати керування LCD у 8-бітному режимі.
4. Створити файли `LCD.h`, `LCD.c` та `main.c`.
5. Реалізувати функції `zapys()`, `lcd_com()`, `lcd_data()`, `lcd_init()` та `lcd_string()`.
6. Створити принципову схему в Proteus.
7. Вивести на LCD ім'я та прізвище латиницею.
8. Перевірити роботу програми.

## 3. Теоретична частина

### 3.1. Алфавітно-символьний LCD

Алфавітно-символьний рідкокристалічний індикатор — це електронний пристрій для відображення літер, цифр і спеціальних символів.

LCD 16×2 має два рядки, кожен із яких може містити до 16 символів.

Для керування дисплеєм використовуються сигнали RS, RW, E та інформаційна шина D0–D7.

### 3.2. Призначення контактів LCD

| Контакт | Призначення |
|---|---|
| RS | Вибір команди або даних |
| RW | Вибір читання або запису |
| E | Дозвіл виконання операції |
| D0–D7 | Передавання восьми бітів даних |
| VSS | Земля |
| VDD | Живлення +5 В |
| VEE | Регулювання контрастності |

У 8-бітному режимі всі вісім інформаційних ліній використовуються одночасно.

### 3.3. Основні команди LCD

| Команда | Код | Призначення |
|---|---|---|
| Function Set | `0x38` | 8-бітний режим, два рядки |
| Display ON | `0x0C` | Увімкнення дисплея |
| Clear Display | `0x01` | Очищення екрана |
| Entry Mode Set | `0x06` | Автоматичне переміщення курсора |
| Set DDRAM Address | `0x80` | Початок першого рядка |
| Set DDRAM Address | `0xC0` | Початок другого рядка |

## 5. Хід виконання роботи

### 5.1. Створення проєкту

У MPLAB X IDE створено проєкт `Practical5_LCD` для мікроконтролера PIC16F877A.

Налаштовано тактову частоту 4 МГц та вибрано компілятор XC8.

Програму розділено на три файли:

- `LCD.h` — оголошення функцій та визначення контактів.
- `LCD.c` — реалізація функцій керування дисплеєм.
- `main.c` — основна програма.

Після компіляції отримано HEX-файл для моделювання.

### 5.2. Реалізація функцій керування LCD

У програмі створено такі функції:

**`zapys()`** — формує імпульс на вході E для передавання інформації дисплею.

**`lcd_com()`** — передає керувальні команди на LCD.

**`lcd_data()`** — передає символи для відображення.

**`lcd_init()`** — виконує ініціалізацію дисплея у 8-бітному режимі.

**`lcd_string()`** — послідовно передає символи текстового рядка.

### 5.3. Створення схеми в Proteus

У середовищі Proteus створено принципову схему з PIC16F877A та LCD LM016L.

Підключення керувальних сигналів:

| LCD | PIC16F877A |
|---|---|
| RS | RB0 |
| RW | RB1 |
| E | RB2 |
| D0–D7 | RD0–RD7 |

До LCD підключено живлення та потенціометр для регулювання контрастності.

### 5.4. Виведення інформації на LCD

Для відображення тексту використано команди встановлення позиції курсора.

На першому рядку дисплея виведено:

`MARIIA`

На другому рядку:

`PETRASHCHUK`

Фрагмент основної програми:

```c
lcd_init();

lcd_com(0x80);
lcd_string("MARIIA");

lcd_com(0xC0);
lcd_string("PETRASHCHUK");
```


### 5.5. Перевірка роботи програми

Програму скомпільовано в MPLAB X IDE та завантажено у мікроконтролер PIC16F877A в Proteus.

Після запуску симуляції LCD відобразив два рядки тексту.

| Параметр | Результат |
|---|---|
| Режим LCD | 8-бітний |
| Кількість рядків | 2 |
| Перший рядок | MARIIA |
| Другий рядок | PETRASHCHUK |
| Частота мікроконтролера | 4 МГц |
| Результат моделювання | Успішно |

## 6. Відповіді на контрольні запитання

**1. Що таке алфавітно-символьний LCD?**

Це рідкокристалічний індикатор, призначений для відображення текстових символів.

**2. Для чого призначений контакт RS?**

RS визначає тип інформації: команда або символ.

**3. Для чого використовується сигнал E?**

Сигнал E забезпечує приймання дисплеєм команди або даних.

**4. Яка різниця між 4-бітним і 8-бітним режимами?**

У 4-бітному режимі байт передається двома частинами, а в 8-бітному — одночасно через вісім ліній.

**5. Для чого використовується команда `0x38`?**

Для налаштування LCD у 8-бітному режимі з двома рядками.

**6. Як очистити дисплей?**

Потрібно передати команду `0x01`.

**7. Як вивести текст на другий рядок?**

Необхідно встановити адресу курсора командою `0xC0`, після чого передати символи.

## 7. Висновок

Під час виконання практичної роботи вивчено принципи керування алфавітно-символьним рідкокристалічним індикатором.

Розроблено програму для мікроконтролера PIC16F877A, яка забезпечує ініціалізацію LCD у 8-бітному режимі, передавання команд і відображення текстової інформації.

У результаті отримано практичні навички програмування мікроконтролерів та керування символьними дисплеями.
