# Практична робота №8

**Тема:** Використання протоколу 1-Wire. Взаємодія мікроконтролера з DS18B20.

**Дисципліна:** Мікроконтролери та їх програмування  
**Виконала:** Петращук Марія  
**Мікроконтролер:** PIC16F877A  
**Середовище розробки:** MPLAB X IDE v6.35, XC8  
**Середовище моделювання:** Proteus 8 Professional

## 1. Мета роботи

Ознайомитися з принципами роботи протоколу 1-Wire, навчитися організовувати обмін інформацією між мікроконтролером PIC16F877A та цифровим датчиком температури DS18B20, реалізувати запис конфігураційних даних і зчитування результатів температурного вимірювання.

## 2. Завдання роботи

1. Ознайомитися з принципами роботи інтерфейсу 1-Wire.
2. Реалізувати програмні функції передавання та приймання бітів і байтів.
3. Виконати ініціалізацію датчика DS18B20.
4. Записати до оперативної пам'яті датчика три байти: TH, TL та регістр конфігурації.
5. Реалізувати запуск вимірювання температури.
6. Зчитати результат вимірювання з пам'яті датчика.
7. Створити принципову схему в Proteus.
8. Перевірити роботу програми при зміні температури.

## 3. Теоретична частина

### 3.1. Протокол 1-Wire

1-Wire — послідовний інтерфейс обміну інформацією, який використовує одну інформаційну лінію та спільну землю.

Обмін даними організовується за принципом ведучого та підлеглого пристроїв. Ведучим виступає мікроконтролер, а підлеглим — цифровий датчик температури.

Для роботи шини використовується підтягувальний резистор, який забезпечує високий логічний рівень за відсутності активного передавання.

### 3.2. Датчик температури DS18B20

DS18B20 — цифровий датчик температури, який передає результати вимірювань через інтерфейс 1-Wire.

Основні характеристики:

- Діапазон вимірювання: від −55 °C до +125 °C.
- Роздільна здатність: 9–12 біт.
- Інтерфейс зв'язку: 1-Wire.
- Живлення: 3,0–5,5 В.
- Максимальний час перетворення при 12-бітній роздільній здатності: 750 мс.

### 3.3. Організація пам'яті DS18B20

Датчик має пам'ять Scratchpad, у якій зберігаються результати вимірювання та конфігураційні параметри.

| Байт | Призначення |
|---|---|
| 0 | Молодший байт температури |
| 1 | Старший байт температури |
| 2 | Верхня межа температури TH |
| 3 | Нижня межа температури TL |
| 4 | Регістр конфігурації |
| 5–7 | Зарезервовані байти |
| 8 | Контрольна сума CRC |

Для запису трьох конфігураційних байтів використовується команда `0x4E` — Write Scratchpad.

### 3.4. Основні команди DS18B20

| Команда | Код | Призначення |
|---|---|---|
| Skip ROM | `0xCC` | Звернення до єдиного датчика на шині |
| Convert T | `0x44` | Запуск вимірювання температури |
| Read Scratchpad | `0xBE` | Читання пам'яті датчика |
| Write Scratchpad | `0x4E` | Запис TH, TL та конфігурації |

## 5. Хід виконання роботи

### 5.1. Створення проєкту

У MPLAB X IDE створено проєкт `Practical8_DS18B20` для мікроконтролера PIC16F877A.

Встановлено тактову частоту 4 МГц і використано компілятор XC8.

Створено програму `main.c`, яка реалізує обмін даними з датчиком температури через інтерфейс 1-Wire.

Після компіляції отримано повідомлення `BUILD SUCCESSFUL`.

### 5.2. Ініціалізація інтерфейсу 1-Wire

Для роботи з датчиком використано контакт RB7 мікроконтролера PIC16F877A.

Створено функції:

- `OW_Low()` — встановлення низького рівня на шині.
- `OW_Release()` — звільнення інформаційної лінії.
- `OW_Reset()` — формування імпульсу скидання та перевірка наявності датчика.
- `OW_WriteBit()` — передавання одного біта.
- `OW_ReadBit()` — зчитування одного біта.
- `OW_WriteByte()` — передавання байта.
- `OW_ReadByte()` — зчитування байта.

### 5.3. Запис конфігурації датчика

Для налаштування DS18B20 створено функцію `DS18B20_Configure()`.

Програма записує до Scratchpad такі значення:

| Параметр | Значення |
|---|---|
| TH | +30 °C |
| TL | +10 °C |
| Конфігурація | `0x7F` |
| Роздільна здатність | 12 біт |

Фрагмент програми:

```c
OW_WriteByte(0xCC);
OW_WriteByte(0x4E);

OW_WriteByte(30);
OW_WriteByte(10);
OW_WriteByte(0x7F);
```

Запис здійснюється до оперативної пам'яті Scratchpad датчика.

### 5.4. Реалізація вимірювання температури

Для запуску температурного перетворення створено функцію `DS18B20_StartConversion()`.

Використано команди:

```c
OW_WriteByte(0xCC);
OW_WriteByte(0x44);
```

Після запуску перетворення програма очікує 750 мс, що відповідає максимальному часу вимірювання при 12-бітній роздільній здатності.

### 5.5. Зчитування результату вимірювання

Для читання температури створено функцію `DS18B20_ReadTemperature()`.

Використано команди:

```c
OW_WriteByte(0xCC);
OW_WriteByte(0xBE);
```

Після цього зчитуються два байти температури.

Результат формується за допомогою операції:

```c
*result = (int16_t)(
    ((uint16_t)high_byte << 8) | low_byte
);
```

Для отримання температури в градусах Цельсія використовується формула:

**T = temperature_raw / 16**

Наприклад, для температури +25 °C результат становить `0x0190`, або 400 у десятковій системі.

### 5.6. Створення принципової схеми

У Proteus створено схему з мікроконтролером PIC16F877A та цифровим датчиком температури DS18B20.

Інформаційну лінію DQ датчика підключено до RB7 мікроконтролера.

Між DQ та +5 В встановлено підтягувальний резистор 4,7 кОм.

До порту PORTD підключено вісім світлодіодів для відображення молодшого байта температурного коду.

### 5.7. Перевірка роботи програми

У Proteus завантажено HEX-файл програми та запущено симуляцію.

Під час зміни температури датчика мікроконтролер виконує нове вимірювання та зчитує результат.

Молодший байт температурного коду відображається на світлодіодах PORTD.


## 6. Результати роботи

Нижче наведено розрахункові значення температурного коду для перевірки програми.

| Температура | Повний код | Молодший байт PORTD |
|---|---|---|
| +10 °C | `0x00A0` | `0xA0` |
| +20 °C | `0x0140` | `0x40` |
| +25 °C | `0x0190` | `0x90` |
| +30 °C | `0x01E0` | `0xE0` |
| −10 °C | `0xFF60` | `0x60` |

Під час моделювання перевірено реакцію програми на зміну температури.

Встановлено, що мікроконтролер зчитує температурний код та передає його молодший байт на PORTD.

## 7. Відповіді на контрольні запитання

**1. Що таке протокол 1-Wire?**

1-Wire — послідовний протокол обміну даними, який використовує одну інформаційну лінію та спільну землю.

**2. Яке призначення резистора 4,7 кОм?**

Він забезпечує підтягування інформаційної лінії DQ до високого логічного рівня.

**3. Для чого використовується команда Skip ROM?**

Для звернення до датчика без передавання його індивідуальної 64-бітної адреси. Застосовується, коли на шині працює один датчик.

**4. Яке призначення команди Convert T?**

Команда запускає вимірювання температури та оновлення температурних регістрів датчика.

**5. Для чого використовується команда Read Scratchpad?**

Для зчитування результату вимірювання та інших даних із пам'яті Scratchpad.

**6. Що означає команда Write Scratchpad?**

Вона дозволяє записати значення TH, TL і регістра конфігурації датчика.

**7. Як визначається температура за цифровим кодом?**

У 12-бітному режимі сире 16-бітне значення температури зі знаком потрібно поділити на 16.

**8. Для чого потрібен імпульс Reset?**

Для початку обміну даними та перевірки наявності датчика на шині.

**9. Який максимальний час вимірювання DS18B20?**

При 12-бітній роздільній здатності максимальний час вимірювання становить 750 мс.

Під час виконання практичної роботи вивчено принципи роботи протоколу 1-Wire та цифрового датчика температури DS18B20.

Розроблено програму для мікроконтролера PIC16F877A, яка забезпечує передавання команд, запис конфігураційних байтів TH, TL та регістра конфігурації, запуск температурного перетворення і зчитування результатів вимірювання.

У середовищі Proteus створено та перевірено схему з датчиком DS18B20. Результат температурного вимірювання відображається у вигляді двійкового коду через світлодіоди PORTD.

У результаті отримано практичні навички програмування інтерфейсу 1-Wire, роботи з цифровими датчиками та моделювання мікроконтролерних систем.
