**Тема:** Використання модуля USART. Передача та прийом інформації.

## 1. Мета роботи

Навчитися застосовувати мікроконтролери для схемотехнічних рішень, освоїти принципи роботи модуля USART та розробити програму для передавання й приймання інформації в асинхронному режимі через інтерфейс UART.

## 2. Завдання роботи

1. Написати програму для обслуговування модуля USART в асинхронному режимі.
2. Виконати ініціалізацію портів мікроконтролера та модуля USART.
3. Реалізувати передавання ASCII-символів власного імені.
4. Реалізувати приймання даних із термінала.
5. Забезпечити пересилання символів із термінала «ПЕРЕДАЧА» до термінала «ПРИЙОМ».
6. Створити принципову схему та перевірити роботу програми в Proteus.

## 3. Теоретична частина

### 3.1. Інтерфейс UART

UART (Universal Asynchronous Receiver/Transmitter) — універсальний асинхронний прийомопередавач, призначений для послідовного обміну даними між електронними пристроями.

Під час асинхронного передавання окремий тактовий сигнал не використовується. Передавач і приймач повинні працювати з однаковою швидкістю обміну.

Для зв'язку застосовуються лінії TX, RX та спільна земля GND.

### 3.2. Модуль USART

USART (Universal Synchronous/Asynchronous Receiver/Transmitter) — вбудований модуль мікроконтролера, який підтримує синхронний та асинхронний обмін інформацією.

У мікроконтролері PIC16F877A використовуються такі контакти:

| Контакт | Призначення |
|---|---|
| RC6/TX | Передавання інформації |
| RC7/RX | Приймання інформації |

В асинхронному режимі USART забезпечує незалежну роботу передавача та приймача.

### 3.3. Формат передавання даних

У програмі використано формат 8N1:

- 1 стартовий біт;
- 8 інформаційних бітів;
- без біта парності;
- 1 стоповий біт.

Швидкість передавання становить 9600 бод.

### 3.4. Основні регістри USART

| Регістр | Призначення |
|---|---|
| TXSTA | Керування передавачем |
| RCSTA | Керування приймачем |
| SPBRG | Встановлення швидкості обміну |
| TXREG | Збереження байта для передавання |
| RCREG | Збереження прийнятого байта |
| PIR1 | Прапорці стану передавання та приймання |

### 3.5. Передавання ASCII-символів

ASCII — стандарт кодування символів, який дозволяє представляти літери, цифри та спеціальні символи у вигляді числових кодів.

Для передавання імені `MARIIA` використовуються такі ASCII-коди:

| Символ | Десятковий код | Шістнадцятковий код |
|---|---:|---|
| M | 77 | 4D |
| A | 65 | 41 |
| R | 82 | 52 |
| I | 73 | 49 |
| I | 73 | 49 |
| A | 65 | 41 |

## 5. Хід виконання роботи

### 5.1. Створення проєкту

У MPLAB X IDE створено проєкт `Practical7_USART` для мікроконтролера PIC16F877A.

Встановлено тактову частоту 4 МГц та вибрано компілятор XC8.

Створено програму `main.c`, яка забезпечує ініціалізацію USART, передавання ASCII-символів та приймання інформації з термінала.

Після компіляції отримано повідомлення `BUILD SUCCESSFUL`.

### 5.2. Ініціалізація модуля USART

Для налаштування USART створено функцію `USART_Init()`.

```c
void USART_Init(void)
{
    TRISCbits.TRISC6 = 1;
    TRISCbits.TRISC7 = 1;

    SPBRG = 25;
    TXSTA = 0x24;
    RCSTA = 0x90;
}
```

Модуль налаштовано на асинхронний режим із швидкістю приблизно 9600 бод.

### 5.3. Реалізація передавання інформації

Для передавання одного символу використано функцію `USART_Write()`.

```c
void USART_Write(char data)
{
    while (!PIR1bits.TXIF)
    {
    }

    TXREG = data;
}
```

Для передавання рядка створено функцію `USART_WriteText()`.

В основній програмі використано команду:

```c
USART_WriteText("MARIIA\r\n");
```

Після запуску програми мікроконтролер передає ім'я `MARIIA` через UART.

### 5.4. Реалізація приймання інформації

Для приймання символів використано функцію `USART_Read()`.

Програма очікує появи даних у регістрі RCREG, після чого зчитує отриманий символ.

Також передбачено обробку помилки переповнення приймального буфера USART.

### 5.5. Створення принципової схеми

У Proteus створено схему з мікроконтролером PIC16F877A та двома віртуальними терміналами.

Підключення:

| PIC16F877A | Термінал |
|---|---|
| RC6/TX | RXD термінала «ПРИЙОМ» |
| RC7/RX | TXD термінала «ПЕРЕДАЧА» |

Для обох терміналів встановлено швидкість 9600 бод, 8 біт даних, відсутність парності та один стоп-біт.

У методичних вказівках також наведено схему фізичного з'єднання через MAX232. У виконаній симуляції використано пряме підключення до віртуальних терміналів Proteus.

## 7. Відповіді на контрольні запитання

**1. Що таке UART?**

UART — універсальний асинхронний прийомопередавач, який використовується для послідовного обміну даними.

**2. Чим відрізняється UART від USART?**

UART підтримує асинхронний обмін, а USART може працювати як в асинхронному, так і в синхронному режимі.

**3. Для чого призначений регістр TXSTA?**

Для керування передавачем USART, вибору режиму роботи та параметрів передавання.

**4. Для чого використовується регістр RCSTA?**

Для керування приймачем USART, увімкнення послідовного порту та контролю помилок приймання.

**5. Яке призначення регістра SPBRG?**

Він визначає швидкість передавання та приймання даних через USART.

**6. Як здійснюється передавання одного символу?**

Програма очікує готовності передавача та записує ASCII-код символу в регістр TXREG.

**7. Як здійснюється приймання одного символу?**

Програма очікує встановлення прапорця RCIF, після чого зчитує прийнятий символ із регістра RCREG.

**8. Для чого використовується MAX232?**

MAX232 забезпечує перетворення логічних рівнів TTL мікроконтролера на рівні інтерфейсу RS-232 і навпаки.

**9. Що означає формат 8N1?**

Вісім інформаційних бітів, відсутність біта парності та один стоповий біт.

**10. Які помилки можуть виникати під час приймання даних?**

Можуть виникати помилка кадру FERR та помилка переповнення приймального буфера OERR.
