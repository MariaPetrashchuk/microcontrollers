
# Практична робота №3

## Тема
Режими роботи модуля TMR0.

## Мета роботи
Отримати практичні навички написання та відлагодження програм у середовищі MPLAB.

## Завдання

1. Закріпити знання з використання модуля TMR0.
2. Вивчити робочі біти керуючого регістра OPTION_REG.
3. Написати програмні фрагменти для роботи з модулем TMR0 мікроконтролера PIC16F84A.

### Завдання 3.1
Налаштувати TMR0 для роботи від внутрішнього джерела Fosc без використання попереднього дільника:
- Забезпечити підрахунок 200 імпульсів.
- Відстежувати стан прапорця T0IF.

### Завдання 3.2
Налаштувати TMR0 для роботи від внутрішнього джерела Fosc без використання попереднього дільника:
- Сформувати на виході RB0 дискретний сигнал.
- Період сигналу T = 220 мс.
- Тривалість високого рівня P = 20 мс.
- Тривалість низького рівня N = 200 мс.

### Завдання 3.3
Налаштувати TMR0 для роботи від внутрішнього джерела Fosc з використанням попереднього дільника:
- Забезпечити періодичне встановлення прапорця T0IF з інтервалом T = 50 мс.

### Завдання 3.4
Налаштувати TMR0 для роботи від внутрішнього джерела Fosc з використанням попереднього дільника:
- Забезпечити формування часового інтервалу T = 500 мс.

## Використані засоби

- Мікроконтролер PIC16F84A.
- MPLAB X IDE v6.35.
- Компілятор MPLAB XC8 v3.10.
- Мова програмування C.

## Теоретичні відомості

### Модуль TMR0

TMR0 — це апаратний 8-розрядний таймер/лічильник мікроконтролера PIC16F84A.

Він використовується для:
- Підрахунку імпульсів.
- Формування часових інтервалів.
- Організації затримок.
- Генерування періодичних сигналів.
- Формування запитів на переривання.

Регістр TMR0 розташований за адресою 01h у банку 0 пам'яті даних.

Таймер може працювати від внутрішнього або зовнішнього джерела тактових імпульсів.

### Регістр OPTION_REG

OPTION_REG — керуючий регістр, який використовується для налаштування режимів роботи TMR0.

Регістр розташований за адресою 81h у банку 1 пам'яті даних.

Основні біти:

- T0CS — вибір джерела тактового сигналу.
- T0SE — вибір фронту зовнішнього сигналу.
- PSA — призначення попереднього дільника.
- PS2:PS0 — вибір коефіцієнта ділення.

При T0CS = 0 використовується внутрішнє джерело тактового сигналу.

При T0CS = 1 використовується зовнішнє джерело через RA4/T0CKI.

При PSA = 0 попередній дільник підключений до TMR0.

При PSA = 1 попередній дільник підключений до WDT, а TMR0 працює без нього.

### Прапорець T0IF

T0IF — прапорець переповнення таймера TMR0, який знаходиться в регістрі INTCON.

Він встановлюється в логічну одиницю при переході значення TMR0 від 255 до 0.

Після обробки переповнення прапорець необхідно скинути програмно.

### Розрахунок тривалості машинного циклу

Для тактової частоти Fosc = 4 МГц:

Tмц = 4 / Fosc

Tмц = 4 / 4 000 000 = 1 мкс

Отже, без попереднього дільника таймер TMR0 збільшується на одиницю кожного машинного циклу, тобто приблизно кожну 1 мкс.


## Хід виконання роботи

### Завдання 3.1. Підрахунок 200 імпульсів

Було розроблено програму для налаштування модуля TMR0 мікроконтролера PIC16F84A.

Таймер працює від внутрішнього джерела тактових імпульсів без використання попереднього дільника.

Для керування режимом роботи використано регістр OPTION_REG.

Параметри налаштування:
- T0CS = 0 — внутрішнє джерело тактування.
- PSA = 1 — попередній дільник призначений WDT.
- Fosc = 4 МГц.
- Тривалість машинного циклу — 1 мкс.

Початкове значення таймера за методикою:

TMR0 = 256 - (200 + 2) = 54.

Програма очікує встановлення прапорця T0IF, який сигналізує про переповнення таймера.

Після переповнення встановлюється змінна overflow_detected = 1 та збільшується лічильник overflow_count.

Очікуваний результат:
- Таймер виконує підрахунок 200 імпульсів.
- Прапорець T0IF встановлюється при переповненні.
- Змінна overflow_count збільшується після кожного переповнення.

Фактичні результати необхідно підтвердити під час відлагодження програми у MPLAB Simulator.


### Завдання 3.2. Формування дискретного сигналу

Для виконання завдання було підготовлено програму мовою C, яка використовує модуль TMR0 для формування прямокутного сигналу на виводі RB0.

Параметри сигналу за завданням:

- Період T = 220 мс.
- Тривалість високого рівня P = 20 мс.
- Тривалість низького рівня N = 200 мс.

Налаштування мікроконтролера:

- Fosc = 4 МГц.
- T0CS = 0 — внутрішнє джерело тактування.
- PSA = 1 — TMR0 працює без попереднього дільника.
- RB0 налаштований на виведення.

Для формування часових інтервалів використано програмні цикли очікування переповнення TMR0.

Теоретичні розрахунки:

- Один повний цикл TMR0 — 256 мкс.
- Для 20 мс потрібно приблизно 78 переповнень.
- Для 200 мс потрібно приблизно 781 переповнення.

Алгоритм роботи:

1. Налаштування порту B.
2. Налаштування таймера TMR0.
3. Встановлення RB0 у логічну одиницю.
4. Формування високого рівня сигналу.
5. Встановлення RB0 у логічний нуль.
6. Формування низького рівня сигналу.
7. Повторення циклу.

Очікуваний результат — періодичний сигнал на RB0 з параметрами, наближеними до заданих.

Фактичну тривалість імпульсів потрібно перевірити за допомогою MPLAB Simulator або осцилографа Proteus.


### Завдання 3.3. Формування інтервалу 50 мс

Для виконання завдання було підготовлено програму мовою C, яка використовує модуль TMR0 із попереднім дільником.

Метою є забезпечення періодичного встановлення прапорця переповнення T0IF з інтервалом 50 мс.

Параметри налаштування:

- Fosc = 4 МГц.
- T0CS = 0 — внутрішнє джерело тактування.
- PSA = 0 — попередній дільник підключений до TMR0.
- PS2:PS0 = 111 — коефіцієнт ділення 1:256.
- OPTION_REG = 0x07.
- Початкове значення TMR0 = 61.

Розрахунок:

Тривалість машинного циклу:

Tмц = 4 / Fosc = 1 мкс.

Тривалість одного відліку з дільником:

Ttick = 256 мкс.

Кількість відліків:

N = 50000 / 256 = 195,3125.

Початкове значення:

TMR0 = 256 - 195 = 61.

Теоретичний часовий інтервал:

T = 195 × 256 = 49920 мкс = 49,92 мс.

Алгоритм роботи:

1. Налаштування регістра OPTION_REG.
2. Вимкнення переривань.
3. Завантаження початкового значення TMR0.
4. Скидання прапорця T0IF.
5. Очікування переповнення таймера.
6. Фіксація переповнення.
7. Збільшення лічильника overflow_count.
8. Повторення циклу.

Очікуваний результат:

Прапорець T0IF періодично встановлюється приблизно кожні 50 мс.

Фактичний інтервал потрібно перевірити у MPLAB Simulator.


### Завдання 3.4. Формування часового інтервалу 500 мс

Для виконання завдання було розроблено програму мовою C, яка використовує модуль TMR0 мікроконтролера PIC16F84A.

Метою програми є формування часового інтервалу тривалістю 500 мс.

Для роботи таймера використано внутрішнє джерело тактових імпульсів із попереднім дільником 1:256.

Параметри налаштування:

- Fosc = 4 МГц.
- T0CS = 0 — внутрішнє джерело тактування.
- PSA = 0 — попередній дільник підключений до TMR0.
- PS2:PS0 = 111 — коефіцієнт ділення 1:256.
- OPTION_REG = 0x07.
- Початкове значення TMR0 = 61.

Розрахунок:

Тривалість машинного циклу:

Tмц = 4 / Fosc = 1 мкс.

Тривалість одного відліку TMR0:

Ttick = 256 мкс.

Для інтервалу 50 мс потрібно приблизно 195 відліків.

Початкове значення таймера:

TMR0 = 256 - 195 = 61.

Для формування інтервалу 500 мс використовується 10 послідовних інтервалів приблизно по 50 мс.

Теоретична тривалість:

T = 10 × 195 × 256 = 499200 мкс = 499,2 мс.

Алгоритм роботи:

1. Налаштування регістра OPTION_REG.
2. Налаштування RB0 на виведення.
3. Завантаження початкового значення TMR0.
4. Скидання прапорця T0IF.
5. Очікування переповнення таймера.
6. Збільшення лічильника interval_count.
7. Повторення до накопичення 10 інтервалів.
8. Встановлення interval_complete = 1.
9. Перемикання стану RB0.
10. Повторення робочого циклу.

Очікуваний результат:

Програма формує часовий інтервал, наближений до 500 мс, після завершення якого змінюється логічний стан виходу RB0.

Фактичну тривалість інтервалу необхідно перевірити у MPLAB Simulator.


## Контрольні запитання

### 1. Для чого призначений модуль TMR0?

Модуль TMR0 — це 8-розрядний таймер/лічильник мікроконтролера PIC16F84A.

Він призначений для підрахунку імпульсів, вимірювання часових інтервалів, формування затримок та організації періодичних подій.

TMR0 може працювати від внутрішнього джерела тактових імпульсів або від зовнішнього сигналу через вивід RA4/T0CKI.

### 2. Які режими роботи має модуль TMR0?

Модуль TMR0 має два основні режими роботи:

1. Режим таймера — підрахунок внутрішніх тактових імпульсів із частотою Fosc/4.
2. Режим лічильника — підрахунок зовнішніх імпульсів, які надходять на вивід RA4/T0CKI.

Режим роботи вибирається за допомогою біта T0CS регістра OPTION_REG.

При T0CS = 0 використовується внутрішнє джерело тактування.

При T0CS = 1 використовується зовнішнє джерело тактування.

### 3. Для чого призначений регістр OPTION_REG?

Регістр OPTION_REG використовується для налаштування параметрів роботи мікроконтролера PIC16F84A.

Він дозволяє вибрати джерело тактування TMR0, фронт зовнішнього сигналу, призначення попереднього дільника та його коефіцієнт ділення.

Основні біти:

- RBPU — керування підтягувальними резисторами PORTB.
- INTEDG — вибір фронту зовнішнього переривання RB0/INT.
- T0CS — вибір джерела тактування TMR0.
- T0SE — вибір фронту зовнішнього сигналу T0CKI.
- PSA — призначення попереднього дільника.
- PS2:PS0 — вибір коефіцієнта ділення.

### 4. Що таке попередній дільник і для чого він використовується?

Попередній дільник (Prescaler) — це апаратний вузол, який зменшує частоту імпульсів, що надходять до таймера.

Він дозволяє збільшувати часовий інтервал між переповненнями TMR0.

Для TMR0 у PIC16F84A доступні коефіцієнти ділення від 1:2 до 1:256.

При PSA = 0 попередній дільник підключається до TMR0.

При PSA = 1 попередній дільник призначається сторожовому таймеру WDT, а TMR0 працює без нього.

### 5. Що таке прапорець T0IF?

T0IF — це прапорець переповнення таймера TMR0, який розташований у регістрі INTCON.

Він автоматично встановлюється в логічну одиницю, коли значення TMR0 переходить від 255 до 0.

Прапорець використовується для визначення моменту переповнення таймера.

Після обробки переповнення T0IF необхідно скинути програмно.

Якщо дозволено переривання TMR0 та глобальні переривання, встановлення T0IF може викликати перехід до обробника переривань.

### 6. Як розрахувати часовий інтервал за допомогою TMR0?

Для розрахунку часового інтервалу необхідно знати частоту тактового генератора, коефіцієнт попереднього дільника та початкове значення TMR0.

Тривалість машинного циклу:

Tмц = 4 / Fosc.

Тривалість одного відліку таймера:

Ttick = Tмц × Prescaler.

Номінальна тривалість до переповнення:

T = (256 - TMR0) × Ttick.

Наприклад, при Fosc = 4 МГц, дільнику 1:256 та TMR0 = 61:

T = (256 - 61) × 256 мкс.

T = 49920 мкс = 49,92 мс.

Цей розрахунок не враховує додатковий час виконання програмних команд і затримку після запису в TMR0.

### 7. Як сформувати часовий інтервал 500 мс за допомогою TMR0?

Оскільки TMR0 є 8-розрядним таймером, одного переповнення недостатньо для формування інтервалу 500 мс при частоті 4 МГц.

Для цього можна використати програмний лічильник переповнень.

При коефіцієнті ділення 1:256 та початковому значенні TMR0 = 61 один інтервал становить номінально 49,92 мс.

Для отримання приблизно 500 мс потрібно виконати 10 таких інтервалів.

Теоретична тривалість:

T = 10 × 49,92 = 499,2 мс.

Після завершення десяти інтервалів програма встановлює ознаку завершення та змінює логічний стан виходу RB0.

Для підвищення точності необхідно врахувати час виконання команд і перевірити результат у MPLAB Simulator.

## Висновок

Під час виконання практичної роботи №3 було вивчено принципи роботи модуля TMR0 мікроконтролера PIC16F84A та особливості його налаштування за допомогою регістра OPTION_REG.

Було розглянуто режими роботи таймера від внутрішнього джерела тактових імпульсів із використанням попереднього дільника та без нього.

Розроблено чотири програми мовою C для виконання поставлених завдань:

1. Підрахунок 200 імпульсів без попереднього дільника.
2. Формування прямокутного сигналу на виході RB0 з періодом 220 мс.
3. Формування інтервалу приблизно 50 мс із використанням попереднього дільника.
4. Формування часового інтервалу приблизно 500 мс за допомогою програмного підрахунку переповнень.

Також було вивчено призначення прапорця T0IF, принципи розрахунку часових інтервалів та особливості використання попереднього дільника.

У результаті було закріплено навички програмування модуля TMR0, роботи з регістрами мікроконтролера та розроблення програм для формування часових інтервалів.

Фактичну точність сформованих інтервалів необхідно підтвердити під час моделювання у MPLAB Simulator.
