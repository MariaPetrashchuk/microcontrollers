
# Практична робота №3

## Тема
Режими роботи модуля TMR0.

## Мета роботи
Отримати практичні навички написання та відлагодження програм у середовищі MPLAB.

## Завдання

1. Закріпити знання з використання модуля TMR0.
2. Вивчити робочі біти керуючого регістра OPTION_REG.
3. Написати програмні фрагменти для роботи з модулем TMR0 мікроконтролера PIC16F84A.

### Завдання 3.1
Налаштувати TMR0 для роботи від внутрішнього джерела Fosc без використання попереднього дільника:
- Забезпечити підрахунок 200 імпульсів.
- Відстежувати стан прапорця T0IF.

### Завдання 3.2
Налаштувати TMR0 для роботи від внутрішнього джерела Fosc без використання попереднього дільника:
- Сформувати на виході RB0 дискретний сигнал.
- Період сигналу T = 220 мс.
- Тривалість високого рівня P = 20 мс.
- Тривалість низького рівня N = 200 мс.

### Завдання 3.3
Налаштувати TMR0 для роботи від внутрішнього джерела Fosc з використанням попереднього дільника:
- Забезпечити періодичне встановлення прапорця T0IF з інтервалом T = 50 мс.

### Завдання 3.4
Налаштувати TMR0 для роботи від внутрішнього джерела Fosc з використанням попереднього дільника:
- Забезпечити формування часового інтервалу T = 500 мс.

## Використані засоби

- Мікроконтролер PIC16F84A.
- MPLAB X IDE v6.35.
- Компілятор MPLAB XC8 v3.10.
- Мова програмування C.
- MPLAB Simulator.
- Proteus 8 Professional.

## Теоретичні відомості

### Модуль TMR0

TMR0 — це апаратний 8-розрядний таймер/лічильник мікроконтролера PIC16F84A.

Він використовується для:
- Підрахунку імпульсів.
- Формування часових інтервалів.
- Організації затримок.
- Генерування періодичних сигналів.
- Формування запитів на переривання.

Регістр TMR0 розташований за адресою 01h у банку 0 пам'яті даних.

Таймер може працювати від внутрішнього або зовнішнього джерела тактових імпульсів.

### Регістр OPTION_REG

OPTION_REG — керуючий регістр, який використовується для налаштування режимів роботи TMR0.

Регістр розташований за адресою 81h у банку 1 пам'яті даних.

Основні біти:

- T0CS — вибір джерела тактового сигналу.
- T0SE — вибір фронту зовнішнього сигналу.
- PSA — призначення попереднього дільника.
- PS2:PS0 — вибір коефіцієнта ділення.

При T0CS = 0 використовується внутрішнє джерело тактового сигналу.

При T0CS = 1 використовується зовнішнє джерело через RA4/T0CKI.

При PSA = 0 попередній дільник підключений до TMR0.

При PSA = 1 попередній дільник підключений до WDT, а TMR0 працює без нього.

### Прапорець T0IF

T0IF — прапорець переповнення таймера TMR0, який знаходиться в регістрі INTCON.

Він встановлюється в логічну одиницю при переході значення TMR0 від 255 до 0.

Після обробки переповнення прапорець необхідно скинути програмно.

### Розрахунок тривалості машинного циклу

Для тактової частоти Fosc = 4 МГц:

Tмц = 4 / Fosc

Tмц = 4 / 4 000 000 = 1 мкс

Отже, без попереднього дільника таймер TMR0 збільшується на одиницю кожного машинного циклу, тобто приблизно кожну 1 мкс.


## Хід виконання роботи

### Завдання 3.1. Підрахунок 200 імпульсів

Було розроблено програму для налаштування модуля TMR0 мікроконтролера PIC16F84A.

Таймер працює від внутрішнього джерела тактових імпульсів без використання попереднього дільника.

Для керування режимом роботи використано регістр OPTION_REG.

Параметри налаштування:
- T0CS = 0 — внутрішнє джерело тактування.
- PSA = 1 — попередній дільник призначений WDT.
- Fosc = 4 МГц.
- Тривалість машинного циклу — 1 мкс.

Початкове значення таймера за методикою:

TMR0 = 256 - (200 + 2) = 54.

Програма очікує встановлення прапорця T0IF, який сигналізує про переповнення таймера.

Після переповнення встановлюється змінна overflow_detected = 1 та збільшується лічильник overflow_count.

Очікуваний результат:
- Таймер виконує підрахунок 200 імпульсів.
- Прапорець T0IF встановлюється при переповненні.
- Змінна overflow_count збільшується після кожного переповнення.

Фактичні результати необхідно підтвердити під час відлагодження програми у MPLAB Simulator.


### Завдання 3.2. Формування дискретного сигналу

Для виконання завдання було підготовлено програму мовою C, яка використовує модуль TMR0 для формування прямокутного сигналу на виводі RB0.

Параметри сигналу за завданням:

- Період T = 220 мс.
- Тривалість високого рівня P = 20 мс.
- Тривалість низького рівня N = 200 мс.

Налаштування мікроконтролера:

- Fosc = 4 МГц.
- T0CS = 0 — внутрішнє джерело тактування.
- PSA = 1 — TMR0 працює без попереднього дільника.
- RB0 налаштований на виведення.

Для формування часових інтервалів використано програмні цикли очікування переповнення TMR0.

Теоретичні розрахунки:

- Один повний цикл TMR0 — 256 мкс.
- Для 20 мс потрібно приблизно 78 переповнень.
- Для 200 мс потрібно приблизно 781 переповнення.

Алгоритм роботи:

1. Налаштування порту B.
2. Налаштування таймера TMR0.
3. Встановлення RB0 у логічну одиницю.
4. Формування високого рівня сигналу.
5. Встановлення RB0 у логічний нуль.
6. Формування низького рівня сигналу.
7. Повторення циклу.

Очікуваний результат — періодичний сигнал на RB0 з параметрами, наближеними до заданих.

Фактичну тривалість імпульсів потрібно перевірити за допомогою MPLAB Simulator або осцилографа Proteus.


### Завдання 3.3. Формування інтервалу 50 мс

Для виконання завдання було підготовлено програму мовою C, яка використовує модуль TMR0 із попереднім дільником.

Метою є забезпечення періодичного встановлення прапорця переповнення T0IF з інтервалом 50 мс.

Параметри налаштування:

- Fosc = 4 МГц.
- T0CS = 0 — внутрішнє джерело тактування.
- PSA = 0 — попередній дільник підключений до TMR0.
- PS2:PS0 = 111 — коефіцієнт ділення 1:256.
- OPTION_REG = 0x07.
- Початкове значення TMR0 = 61.

Розрахунок:

Тривалість машинного циклу:

Tмц = 4 / Fosc = 1 мкс.

Тривалість одного відліку з дільником:

Ttick = 256 мкс.

Кількість відліків:

N = 50000 / 256 = 195,3125.

Початкове значення:

TMR0 = 256 - 195 = 61.

Теоретичний часовий інтервал:

T = 195 × 256 = 49920 мкс = 49,92 мс.

Алгоритм роботи:

1. Налаштування регістра OPTION_REG.
2. Вимкнення переривань.
3. Завантаження початкового значення TMR0.
4. Скидання прапорця T0IF.
5. Очікування переповнення таймера.
6. Фіксація переповнення.
7. Збільшення лічильника overflow_count.
8. Повторення циклу.

Очікуваний результат:

Прапорець T0IF періодично встановлюється приблизно кожні 50 мс.

Фактичний інтервал потрібно перевірити у MPLAB Simulator.
