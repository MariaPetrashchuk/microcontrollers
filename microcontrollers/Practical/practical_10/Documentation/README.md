# Практична робота №10

**Тема:** Ініціалізація модуля графічного LCD. Написання функцій графічних примітивів. Виведення текстової інформації.

**Дисципліна:** Мікроконтролери та їх програмування  
**Виконала:** Петращук Марія  
**Мікроконтролер:** PIC16F877A  
**Дисплей:** Nokia 6610  
**Середовище розробки:** MPLAB X IDE v6.35, XC8  
**Середовище моделювання:** Proteus 8 Professional

## 1. Мета роботи

Навчитися використовувати мікроконтролер PIC16F877A для керування графічним дисплеєм Nokia 6610, виконувати його ініціалізацію, здійснювати передавання команд і даних через інтерфейс SPI, створювати графічні примітиви та виводити текстову інформацію.

## 2. Завдання роботи

1. Написати програму для мікроконтролера PIC16F877A для роботи з дисплеєм Nokia 6610.
2. Виконати ініціалізацію портів мікроконтролера.
3. Реалізувати функції `lcd_trans()`, `lcd_trans_com()` та `lcd_trans_data()`.
4. Провести ініціалізацію дисплея Nokia 6610.
5. Створити функцію `BOX_DRW()` для заливки прямокутної області кольором.
6. Реалізувати встановлення курсора, малювання пікселя, лінії та кола.
7. Реалізувати виведення текстової інформації у символьних комірках 8×8.
8. Перевірити роботу програми у Proteus.

## 3. Теоретична частина

### 3.1. Графічний LCD Nokia 6610

Графічний рідкокристалічний дисплей Nokia 6610 призначений для відображення кольорових зображень, графічних елементів та тексту.

Основні характеристики:

- Роздільна здатність — 132×132 пікселі.
- Кількість кольорів — 4096.
- Формат кольору — 12-бітний RGB.
- Контролер — Philips PCF8833 або Epson S1D15G10.
- Інтерфейс передавання даних — SPI.

У практичній роботі розглядається дисплей із контролером Philips PCF8833.

### 3.2. Інтерфейс SPI

SPI — синхронний послідовний інтерфейс для обміну інформацією між мікроконтролером та периферійними пристроями.

Основні сигнали:

- **SCK** — тактовий сигнал.
- **SDO** — вихід даних мікроконтролера.
- **CS** — вибір дисплея.
- **RESET** — апаратне скидання контролера.

Особливістю дисплея Nokia 6610 є використання 9-бітного формату передавання. Перший біт визначає тип інформації: команда або дані. Наступні вісім бітів містять значення команди чи даних.

### 3.3. Основні команди контролера PCF8833

| Команда | Код | Призначення |
|---|---|---|
| SWRESET | `0x01` | Програмне скидання |
| SLEEPOUT | `0x11` | Вихід із режиму сну |
| BSTRON | `0x03` | Увімкнення перетворювачів напруги |
| DISPON | `0x29` | Увімкнення дисплея |
| NORON | `0x13` | Нормальний режим відображення |
| CASET | `0x2A` | Встановлення адрес стовпців |
| PASET | `0x2B` | Встановлення адрес рядків |
| RAMWR | `0x2C` | Запис у пам'ять дисплея |
| COLMOD | `0x3A` | Вибір формату кольору |
| MADCTL | `0x36` | Налаштування орієнтації |
| SETCON | `0x25` | Налаштування контрастності |

## 5. Хід виконання роботи

### 5.1. Створення проєкту

У середовищі MPLAB X IDE створено проєкт `Practical10_LCD` для мікроконтролера PIC16F877A.

Для написання програми використано мову C та компілятор XC8.

Встановлено тактову частоту 4 МГц.

Програму скомпільовано з повідомленням `BUILD SUCCESSFUL`.

### 5.2. Ініціалізація мікроконтролера

Для роботи з дисплеєм використано контакти:

| Контакт PIC16F877A | Призначення |
|---|---|
| RC2 | CS |
| RC3 | SCK |
| RC5 | DATA |
| RC6 | RESET |

Ініціалізація виконується функцією `Init_MK()`.

У програмі налаштовано напрямки портів та модуль MSSP для передавання інформації через SPI.

### 5.3. Передавання команд і даних

Для передавання інформації реалізовано функції:

- `lcd_trans()` — передавання восьми бітів через SPI.
- `lcd_trans_com()` — передавання команди дисплею.
- `lcd_trans_data()` — передавання даних дисплею.

Функція `lcd_send9()` формує дев'ятибітну посилку, яка містить керувальний біт D/C та вісім інформаційних бітів.

### 5.4. Ініціалізація LCD

Ініціалізацію реалізовано функцією `LCD_Init()`.

Послідовність основних операцій:

1. Апаратне скидання дисплея.
2. Програмне скидання контролера.
3. Вихід із режиму сну.
4. Увімкнення дисплея.
5. Налаштування адресної області.
6. Встановлення формату кольору.
7. Налаштування орієнтації.
8. Встановлення контрастності.

Після ініціалізації дисплей готовий до відображення графічної та текстової інформації.

### 5.5. Реалізація графічних примітивів

Для роботи з графікою створено такі функції:

| Функція | Призначення |
|---|---|
| `LCD_SetCursor()` | Встановлення координат пікселя |
| `LCD_Pixel()` | Малювання окремого пікселя |
| `BOX_DRW()` | Заливка прямокутної області |
| `LCD_Line()` | Малювання відрізка |
| `LCD_Circle()` | Малювання кола |

Для побудови ліній використано алгоритм Брезенхема, який дозволяє малювати відрізки за допомогою цілочисельних обчислень.

Для побудови кола використано алгоритм середньої точки.

### 5.6. Виведення текстової інформації

Для відображення тексту реалізовано функції:

- `LCD_Char8x8()` — малювання одного символу.
- `LCD_Text()` — виведення послідовності символів.

У програмі використано шрифт 5×7, розміщений у комірці розміром 8×8 пікселів.

Підтримуються великі латинські літери, цифри та пробіл.

### 5.7. Створення принципової схеми

У середовищі Proteus створено схему підключення графічного дисплея Nokia 6610 до мікроконтролера PIC16F877A.

## 7. Відповіді на контрольні запитання

**1. Для чого призначений графічний LCD?**

Для відображення графічної, символьної та кольорової інформації.

**2. Яка роздільна здатність дисплея Nokia 6610?**

132×132 пікселі.

**3. Який інтерфейс використовується для керування дисплеєм?**

Послідовний синхронний інтерфейс SPI.

**4. Чому для Nokia 6610 використовується 9-бітна посилка?**

Перший біт визначає, чи передається команда, чи дані. Наступні вісім бітів містять інформацію.

**5. Для чого призначена команда CASET?**

Для встановлення початкової та кінцевої адрес стовпців дисплея.

**6. Для чого призначена команда PASET?**

Для встановлення початкової та кінцевої адрес рядків дисплея.

**7. Яке призначення команди RAMWR?**

Для запису інформації у графічну пам'ять дисплея.

**8. Для чого використовується функція BOX_DRW()?**

Для заповнення прямокутної області дисплея заданим кольором.

**9. Як здійснюється виведення тексту?**

За допомогою послідовного малювання пікселів кожного символу відповідно до таблиці шрифту.

**10. Які графічні примітиви реалізовано?**

Малювання пікселя, прямокутника, лінії та кола.

## 8. Висновок

Під час виконання практичної роботи вивчено принципи керування графічним дисплеєм Nokia 6610 за допомогою мікроконтролера PIC16F877A.

Розроблено програму ініціалізації дисплея та передавання команд і даних через інтерфейс SPI.

Реалізовано функції заливки прямокутної області кольором, малювання окремих пікселів, ліній і кіл, а також виведення текстової інформації.

Отримано практичні навички програмування графічних дисплеїв, роботи з контролером PCF8833 та створення графічних елементів мовою C.
