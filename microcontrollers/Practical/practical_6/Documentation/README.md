# Практична робота №6

**Тема:** Робота з модулем АЦП.

**Дисципліна:** Мікроконтролери та їх програмування  
**Виконала:** Петращук Марія  
**Мікроконтролер:** PIC16F877A  
**Середовище розробки:** MPLAB X IDE v6.35, XC8  
**Середовище моделювання:** Proteus 8 Professional

## 1. Мета роботи

Навчитися застосовувати мікроконтролери для схемотехнічних рішень, освоїти принципи роботи 10-розрядного аналого-цифрового перетворювача та написати програму для вимірювання аналогового сигналу з відображенням результатів на світлодіодах.

## 2. Завдання роботи

1. Написати програму для роботи з 10-розрядним АЦП мікроконтролера PIC16F877A.
2. Виконати ініціалізацію портів і модуля АЦП.
3. Налаштувати аналоговий канал RA0/AN0.
4. Реалізувати безперервне вимірювання вхідної напруги.
5. Вивести результат перетворення на 10 світлодіодів через PORTB та PORTC.
6. Створити принципову схему в Proteus.
7. Перевірити роботу програми при зміні аналогового сигналу.

## 3. Теоретична частина

### 3.1. Аналого-цифровий перетворювач

Аналого-цифровий перетворювач (АЦП) — електронний пристрій, який перетворює аналоговий сигнал у цифровий код.

Мікроконтролер PIC16F877A має вбудований 10-розрядний АЦП, який підтримує вісім аналогових каналів AN0–AN7.

Результат перетворення має діапазон від 0 до 1023.

За опорної напруги 5 В роздільна здатність АЦП становить приблизно 4,88 мВ на один рівень квантування.

### 3.2. Основні регістри АЦП

Для роботи з модулем АЦП використовуються чотири основні регістри.

| Регістр | Призначення |
|---|---|
| ADCON0 | Вибір каналу, тактування та керування перетворенням |
| ADCON1 | Налаштування аналогових входів і формату результату |
| ADRESH | Старший байт результату |
| ADRESL | Молодший байт результату |

У програмі використано праве вирівнювання результату, тому два старші біти зберігаються в ADRESH, а вісім молодших — в ADRESL.

### 3.3. Алгоритм роботи АЦП

1. Налаштування аналогового входу.
2. Вибір каналу AN0.
3. Увімкнення модуля АЦП.
4. Очікування заряджання внутрішнього конденсатора.
5. Запуск аналого-цифрового перетворення.
6. Очікування завершення перетворення.
7. Зчитування результату з регістрів ADRESH та ADRESL.
8. Виведення цифрового коду на світлодіоди.

## 5. Хід виконання роботи

### 5.1. Створення проєкту

У середовищі MPLAB X IDE створено проєкт `Practical6_ADC` для мікроконтролера PIC16F877A.

Налаштовано тактову частоту 4 МГц та використано компілятор XC8.

Створено програму `main.c`, яка забезпечує ініціалізацію АЦП, вимірювання напруги та відображення цифрового результату.

### 5.2. Ініціалізація модуля АЦП

Для роботи з аналоговим сигналом налаштовано вхід RA0/AN0.

Основні налаштування:

```c
TRISA = 0x01;
TRISB = 0x00;
TRISC = 0x00;

ADCON1 = 0x8E;
ADCON0 = 0x81;
```

Регістр ADCON1 налаштовує канал AN0 як аналоговий вхід та встановлює праве вирівнювання результату.

Регістр ADCON0 вибирає канал AN0, тактування Fosc/32 та вмикає модуль АЦП.

### 5.3. Реалізація аналого-цифрового перетворення

Створено функцію `ADC_Read()`, яка виконує вимірювання аналогового сигналу.

Фрагмент програми:

```c
uint16_t ADC_Read(void)
{
    __delay_us(40);

    ADCON0bits.GO_nDONE = 1;

    while (ADCON0bits.GO_nDONE);

    PIR1bits.ADIF = 0;

    return ((uint16_t)ADRESH << 8) | ADRESL;
}
```

Після завершення перетворення результат зчитується з регістрів ADRESH та ADRESL.

### 5.4. Створення принципової схеми

У Proteus створено схему на основі мікроконтролера PIC16F877A.

До входу RA0/AN0 підключено потенціометр, який забезпечує зміну аналогової напруги від 0 до 5 В.

До портів PORTB і PORTC підключено десять світлодіодів через струмообмежувальні резистори.

### 5.5. Виведення результату на світлодіоди

У головному циклі програми результат АЦП передається на вихідні порти:

```c
while (1)
{
    adc_result = ADC_Read();

    PORTB = (uint8_t)(adc_result & 0xFF);
    PORTC = (uint8_t)((adc_result >> 8) & 0x03);

    __delay_ms(40);
}
```

Вісім молодших бітів результату відображаються через RB0–RB7, а два старших — через RC0–RC1.

### 5.6. Перевірка роботи програми

У Proteus завантажено HEX-файл та запущено симуляцію.

Під час зміни положення потенціометра змінюється аналогова напруга на вході RA0/AN0.

АЦП перетворює її на цифровий код, який відображається станами десяти світлодіодів.

## 6. Результати роботи

Для опорної напруги 5 В отримано такі розрахункові значення:

| Вхідна напруга | Код АЦП (приблизно) | Двійковий код |
|---|---:|---|
| 0 В | 0 | 0000000000 |
| 1 В | 205 | 0011001101 |
| 2 В | 409 | 0110011001 |
| 2,5 В | 512 | 1000000000 |
| 3 В | 614 | 1001100110 |
| 4 В | 818 | 1100110010 |
| 5 В | 1023 | 1111111111 |

Під час моделювання підтверджено, що зі зміною аналогової напруги змінюється двійковий код на виходах мікроконтролера.

## 7. Відповіді на контрольні запитання

**1. З чого складається модуль АЦП?**

Модуль АЦП складається з мультиплексора аналогових каналів, схеми вибірки-зберігання, перетворювача, системи керування та регістрів результату.

**2. Який алгоритм роботи модуля АЦП?**

Налаштування каналу, заряджання внутрішнього конденсатора, запуск перетворення, очікування завершення та зчитування цифрового результату.

**3. Як задається тактування ЦАП?**

У контексті роботи АЦП тактування перетворення задається бітами ADCS1 і ADCS0 регістра ADCON0. Можна вибрати частоту від генератора мікроконтролера або внутрішнього RC-генератора.

**4. Які регістри використовуються для забезпечення роботи АЦП?**

ADCON0, ADCON1, ADRESH та ADRESL.

**5. Як функціонує модуль АЦП у режимі SLEEP?**

АЦП може виконувати перетворення в режимі SLEEP за умови використання внутрішнього RC-генератора тактування АЦП. Завершення перетворення може спричинити пробудження мікроконтролера, якщо відповідні переривання налаштовані.

**6. У яких регістрах зберігається результат АЦ-перетворення?**

У регістрах ADRESH та ADRESL.

**7. Для чого призначений регістр ADCON1?**

Для налаштування аналогових входів, опорної напруги та формату збереження результату перетворення.

**8. Як здійснюється запуск АЦ-перетворення?**

Встановленням біта GO/DONE регістра ADCON0 у логічну одиницю.

**9. Як виводиться інформація на знакосимвольний РКІ для цілої та дробової частини?**

Числове значення розділяється на цілу та дробову частини. Потім ці частини перетворюються на символьні рядки та послідовно передаються на LCD за допомогою функцій виведення символів.

Під час виконання практичної роботи вивчено принципи роботи 10-розрядного аналого-цифрового перетворювача мікроконтролера PIC16F877A.

Розроблено програму для безперервного вимірювання аналогової напруги на вході RA0/AN0 та відображення результату перетворення через порти PORTB і PORTC.

У середовищі Proteus перевірено роботу схеми з потенціометром і десятьма світлодіодами. Встановлено, що зміна вхідної напруги призводить до відповідної зміни цифрового коду.

У результаті отримано практичні навички налаштування АЦП, роботи з регістрами мікроконтролера та моделювання електронних схем.
