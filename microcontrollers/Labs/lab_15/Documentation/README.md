# Лабораторна робота №15

**Тема:** Робота з EEPROM за протоколом I2C.

**Дисципліна:** Мікроконтролери та їх програмування  
**Виконала:** Петращук Марія  
**Мікроконтролер:** PIC16F877A  
**Мікросхема пам'яті:** EEPROM 24C16  
**Середовище розробки:** MPLAB X IDE v6.35, XC8  
**Середовище моделювання:** Proteus 8 Professional

## 1. Мета роботи

Навчитися застосовувати модуль послідовного синхронного порту MSSP мікроконтролера в режимі I2C для реалізації обміну інформацією із зовнішньою пам'яттю EEPROM 24C16. Дослідити процеси запису та читання інформаційних байтів.

## 2. Завдання лабораторної роботи

1. Ознайомитися з принципами роботи протоколу I2C.
2. Створити схему взаємодії PIC16F877A та EEPROM 24C16.
3. Налаштувати модуль MSSP у режимі I2C.
4. Реалізувати основні функції передавання та приймання даних.
5. Записати інформаційний байт за адресою `00h` EEPROM.
6. Зчитати записаний байт із пам'яті.
7. Перевірити роботу програми в Proteus.
8. Вивести отриману інформацію на PORTD.

## 3. Теоретична частина

### 3.1. Протокол I2C

I2C — це послідовний синхронний інтерфейс, призначений для обміну інформацією між електронними пристроями.

Для передавання даних використовуються дві сигнальні лінії:

- **SDA** — лінія передавання даних.
- **SCL** — лінія тактового сигналу.

Обмін здійснюється між ведучим пристроєм (Master) і веденим (Slave).

Передавання починається сигналом START і завершується сигналом STOP. Після кожного переданого байта приймач формує підтвердження ACK або NACK.

### 3.2. EEPROM 24C16

24C16 — це енергонезалежна мікросхема пам'яті обсягом 2048 байтів, яка підтримує інтерфейс I2C.

Основні характеристики:

- Обсяг пам'яті — 16 Кбіт.
- Збереження інформації без живлення.
- Послідовний інтерфейс I2C.
- Можливість запису та читання окремих байтів.
- Організація пам'яті у вигляді восьми блоків по 256 байтів.

### 3.3. Модуль MSSP

MSSP — апаратний модуль мікроконтролера PIC16F877A, який забезпечує обмін інформацією через SPI або I2C.

Основні регістри:

| Регістр | Призначення |
|---|---|
| SSPCON | Керування модулем MSSP |
| SSPCON2 | Керування операціями START, STOP, ACK |
| SSPSTAT | Стан модуля |
| SSPBUF | Передавання та приймання байтів |
| SSPADD | Налаштування швидкості I2C |

## 5. Хід виконання роботи

### 5.1. Створення проєкту

У MPLAB X IDE створено проєкт `Lab15_I2C_EEPROM` для мікроконтролера PIC16F877A.

Написано програму мовою C, яка забезпечує обмін інформацією між мікроконтролером і EEPROM 24C16 через інтерфейс I2C.

Програму скомпільовано за допомогою XC8 та отримано HEX-файл.

### 5.2. Створення схеми в Proteus

У середовищі Proteus створено схему з PIC16F877A та EEPROM 24C16.

Підключення виконано таким чином:

| PIC16F877A | EEPROM 24C16 |
|---|---|
| RC3/SCL | SCL |
| RC4/SDA | SDA |
| +5V | VCC |
| GND | GND |

До ліній SDA та SCL підключено підтягувальні резистори 10 кОм.

До порту PORTD підключено вісім світлодіодів для відображення результатів читання.

### 5.3. Ініціалізація I2C

Для налаштування інтерфейсу створено функцію `I2C_Init()`.

Виконано:

- Налаштування RC3 та RC4 як входів.
- Заборону глобальних переривань.
- Увімкнення модуля MSSP у режимі I2C Master.
- Налаштування швидкості передавання 100 кГц.
- Очищення регістра SSPCON2.

Для визначення значення SSPADD використано формулу:

**F_I2C = Fosc / (4 × (SSPADD + 1))**

За частоти генератора 4 МГц:

**SSPADD = 9**

Отже, частота роботи шини становить 100 кГц.

### 5.4. Реалізація основних функцій

У програмі реалізовано:

- `I2C_Init()` — ініціалізація інтерфейсу.
- `I2C_Start()` — формування START.
- `I2C_Restart()` — повторний START.
- `I2C_Stop()` — формування STOP.
- `I2C_Trans()` — передавання байта.
- `I2C_Receive()` — приймання байта з формуванням ACK або NACK.
- `EEPROM_WriteByte()` — запис інформації в EEPROM.
- `EEPROM_ReadByte()` — читання інформації з EEPROM.

### 5.5. Запис байта в EEPROM

Для перевірки роботи програми обрано інформаційний байт `A5h`.

Запис здійснюється за адресою пам'яті `00h`.

Послідовність операцій:

1. Формування START.
2. Передавання керувального байта `A0h`.
3. Передавання адреси комірки `00h`.
4. Передавання інформаційного байта `A5h`.
5. Формування STOP.
6. Очікування завершення внутрішнього циклу запису EEPROM.

### 5.6. Читання байта з EEPROM

Після запису реалізовано читання інформації з тієї самої комірки пам'яті.

Послідовність:

1. START.
2. Передавання `A0h`.
3. Передавання адреси `00h`.
4. Повторний START.
5. Передавання `A1h`.
6. Приймання інформаційного байта.
7. Формування NACK.
8. STOP.

Після читання отримано значення `A5h`, яке відповідає раніше записаному байту.

### 5.7. Перевірка результатів

У Proteus виконано моделювання запису та читання EEPROM 24C16.

Отримані результати:

| Адреса пам'яті | `00h` |

## 7. Відповіді на контрольні запитання

**1. Що таке інтерфейс I2C?**

I2C — це послідовний синхронний інтерфейс, який використовує дві сигнальні лінії для передавання даних між електронними пристроями.

**2. Яке призначення ліній SDA та SCL?**

SDA призначена для передавання інформації, а SCL — для формування тактових імпульсів.

**3. Що означають сигнали START та STOP?**

START повідомляє про початок обміну інформацією, а STOP — про його завершення.

**4. Для чого використовується сигнал ACK?**

ACK підтверджує успішне приймання переданого байта.

**5. Що таке EEPROM?**

EEPROM — це енергонезалежна пам'ять, інформацію в якій можна електрично записувати та стирати.

**6. Для чого призначений модуль MSSP?**

MSSP забезпечує апаратну реалізацію послідовних інтерфейсів SPI та I2C.

**7. Як налаштувати швидкість I2C?**

Швидкість визначається частотою генератора мікроконтролера та значенням регістра SSPADD.

**8. Як здійснюється читання з EEPROM?**

Спочатку передається адреса комірки пам'яті, потім формується повторний START і виконується приймання інформаційного байта.

## 8. Висновок

Під час виконання лабораторної роботи вивчено особливості протоколу I2C та принципи роботи зовнішньої енергонезалежної пам'яті EEPROM 24C16.

Розроблено програму для мікроконтролера PIC16F877A, яка забезпечує ініціалізацію модуля MSSP, формування сигналів START і STOP, передавання та приймання інформаційних байтів.

У середовищі Proteus перевірено запис байта `A5h` за адресою `00h` та його подальше читання. Прочитане значення збігається із записаним.

Результат відображено на світлодіодах порту PORTD у вигляді двійкової комбінації `10100101`.

У результаті отримано практичні навички роботи з інтерфейсом I2C, модулем MSSP та зовнішньою пам'яттю EEPROM.
