# Лабораторна робота №1

## Тема роботи

Ознайомлення із середовищем розробки MPLAB X IDE та відлагоджувачем Simulator.

## Мета роботи

Ознайомитися з інтерфейсом та основними можливостями інтегрованого середовища розробки MPLAB X IDE. Навчитися створювати проєкти для мікроконтролера PIC16F84A, компілювати програми мовою C за допомогою компілятора XC8 та виконувати покрокове відлагодження програм у симуляторі.

## Хід виконання роботи

### 1. Підготовка середовища розробки

Для виконання лабораторної роботи використано середовище MPLAB X IDE версії 6.35 та компілятор XC8 версії 3.10.

У репозиторії `microcontrollers` створено папку `Labs`, у якій розміщено папку `lab_1` із двома підпапками:

- `Source` — для зберігання програмного коду.
- `Documentation` — для зберігання звіту та результатів роботи.

### 2. Створення проєкту

У середовищі MPLAB X IDE створено новий проєкт за допомогою команди **File → New Project**.

Під час створення проєкту виконано такі налаштування:

1. Обрано категорію Microchip Embedded та тип Application Project.
2. Вибрано мікроконтролер PIC16F84A.
3. Як інструмент відлагодження встановлено Simulator.
4. Обрано компілятор XC8 (v3.10).
5. Вказано назву проєкту та місце його збереження.

### 3. Написання програмного коду

У розділі Source Files створено файл `main.c`.

У програмі підключено бібліотеку `xc.h`, налаштовано конфігураційні біти мікроконтролера та оголошено глобальну змінну `TMP`.

**Лістинг програми main.c:**

```c
#include <xc.h>

#pragma config FOSC = XT
#pragma config WDTE = OFF
#pragma config PWRTE = OFF
#pragma config CP = OFF

unsigned char TMP;

void main(void) {
    TMP = 0;

    while (1) {
        TMP = TMP + 2;
        TMP--;
    }

    return;
}
```

**Пояснення програмного коду:**

- `#include <xc.h>` — підключення бібліотеки для роботи з мікроконтролером.
- `#pragma config` — встановлення конфігураційних параметрів мікроконтролера.
- `unsigned char TMP` — оголошення глобальної 8-бітної змінної.
- `void main(void)` — головна функція програми.
- `TMP = 0` — встановлення початкового значення змінної.
- `while(1)` — нескінченний цикл виконання програми.
- `TMP = TMP + 2` — збільшення значення змінної на 2.
- `TMP--` — зменшення значення змінної на 1.

Після кожної повної ітерації циклу значення змінної `TMP` збільшується на одиницю.

### 4. Компіляція програми

Після написання програмного коду виконано компіляцію проєкту за допомогою команди **Clean and Build Main Project (Shift + F11)**.

Для компіляції використано XC8.

Після успішної збірки у вікні Output з'явилося повідомлення:

`BUILD SUCCESSFUL`

Це підтверджує, що програму було скомпільовано без помилок, які перешкоджають збірці.

### 5. Відлагодження програми

Для перевірки роботи програми використано вбудований симулятор MPLAB X IDE.

Відлагодження запущено командою **Debug Main Project**.

У вікні Watches додано глобальну змінну `TMP`, що дозволило спостерігати за зміною її значення.

Покрокове виконання програми здійснювалося за допомогою клавіші **F7 (Step Into)**.

Під час відлагодження перевірено виконання арифметичних операцій та роботу нескінченного циклу.

## Вихідний контроль

### 1. Яке призначення середовища MPLAB X IDE?

MPLAB X IDE — це інтегроване середовище розробки програмного забезпечення для мікроконтролерів Microchip. Воно використовується для написання програм, створення та керування проєктами, компіляції програмного коду, програмування мікроконтролерів і відлагодження програм.

### 2. Для чого використовується програмний симулятор (Simulator)?

Simulator призначений для моделювання роботи мікроконтролера без використання фізичного обладнання. Він дозволяє виконувати програму покроково, переглядати значення змінних, аналізувати стан регістрів і виявляти помилки в програмному коді.

### 3. Яку роль відіграє нескінченний цикл while(1) у програмах для мікроконтролерів?

Нескінченний цикл `while(1)` забезпечує постійне повторення команд програми. Оскільки мікроконтролер повинен безперервно виконувати задані операції, цей цикл дозволяє організувати його основний робочий процес.

За допомогою симулятора було досліджено покрокове виконання програми та зміну значення глобальної змінної `TMP` у нескінченному циклі.
