
# Лабораторна робота №5

## Тема
Режими роботи модуля TMR0.

## Мета роботи
Отримати практичні навички написання та відлагодження програм у середовищі MPLAB.

## Завдання

1. Закріпити знання з використання модуля TMR0.
2. Вивчити робочі біти керуючого регістра OPTION_REG.
3. Написати програми для роботи з модулем TMR0 мікроконтролера PIC16F84A.

### Завдання 3.1
Налаштувати TMR0 для роботи від внутрішнього джерела тактового сигналу без використання попереднього дільника.

Забезпечити підрахунок 200 імпульсів та відстеження прапорця T0IF.

### Завдання 3.2
Налаштувати TMR0 для роботи від внутрішнього джерела без попереднього дільника.

Забезпечити формування на RB0 дискретного сигналу з періодом 220 мс:
- Високий рівень — 20 мс.
- Низький рівень — 200 мс.

### Завдання 3.3
Налаштувати TMR0 із використанням попереднього дільника.

Забезпечити періодичне встановлення прапорця T0IF з інтервалом 50 мс.

### Завдання 3.4
Налаштувати TMR0 із використанням попереднього дільника.

Забезпечити формування часового інтервалу 500 мс.

### Завдання 3.5
Реалізувати динамічну індикацію на семисегментному індикаторі з використанням TMR0.

Забезпечити період оновлення розрядів 10–20 мс.

Перевірити часові характеристики в MPLAB Simulator та роботу програми в Proteus.

## Використане обладнання та програмне забезпечення

- Мікроконтролер PIC16F84A.
- MPLAB X IDE v6.35.
- Компілятор MPLAB XC8 v3.10.
- Proteus 8 Professional.
- Мова програмування C.
- Семисегментний індикатор.

## Теоретичні відомості

### Модуль TMR0

TMR0 — це апаратний восьмибітний таймер/лічильник мікроконтролера PIC16F84A.

Він може працювати у двох режимах:

1. Режим таймера — підрахунок імпульсів внутрішнього тактового сигналу.
2. Режим лічильника — підрахунок зовнішніх імпульсів, які надходять на вивід RA4/T0CKI.

Регістр TMR0 може зберігати значення від 0 до 255.

Після переходу від 255 до 0 відбувається переповнення таймера та встановлюється прапорець T0IF у регістрі INTCON.

### Регістр OPTION_REG

Для налаштування TMR0 використовується регістр OPTION_REG.

Основні керуючі біти:

- T0CS — вибір внутрішнього або зовнішнього джерела тактування.
- T0SE — вибір фронту зовнішнього сигналу.
- PSA — призначення попереднього дільника.
- PS2, PS1, PS0 — вибір коефіцієнта ділення.

Якщо T0CS = 0, таймер використовує внутрішній сигнал Fosc/4.

Якщо T0CS = 1, використовується зовнішній сигнал на RA4/T0CKI.

Якщо PSA = 0, попередній дільник підключений до TMR0.

Якщо PSA = 1, попередній дільник підключений до сторожового таймера WDT.

### Попередній дільник

Попередній дільник дозволяє зменшити частоту імпульсів, що надходять на TMR0.

Для TMR0 доступні коефіцієнти ділення від 1:2 до 1:256.

Використання попереднього дільника дозволяє формувати більші часові інтервали без частого переповнення таймера.

### Тривалість машинного циклу

При тактовій частоті Fosc = 4 МГц:

Tcy = 4 / Fosc.

Tcy = 4 / 4 000 000 = 1 мкс.

Отже, без попереднього дільника значення TMR0 збільшується приблизно кожну 1 мкс.


## Хід виконання роботи

### Завдання 3.1. Підрахунок 200 імпульсів за допомогою TMR0

Було розроблено програму для мікроконтролера PIC16F84A, яка забезпечує підрахунок 200 імпульсів внутрішнього тактового сигналу з використанням модуля TMR0.

Тактова частота мікроконтролера становить 4 МГц.

Для роботи таймера вибрано внутрішнє джерело тактування без використання попереднього дільника.

Налаштування виконується через регістр OPTION_REG.

Значення OPTION_REG = 0x88 забезпечує роботу TMR0 від внутрішнього тактового сигналу та призначення попереднього дільника сторожовому таймеру WDT.

#### Розрахунок параметрів

Тривалість машинного циклу:

Tcy = 4 / 4 000 000 = 1 мкс.

Необхідна кількість імпульсів:

N = 200.

Розрахунковий інтервал:

T = 200 × 1 = 200 мкс.

Початкове значення таймера без корекції:

TMR0 = 256 - 200 = 56.

З урахуванням затримки двох машинних циклів після запису в TMR0:

TMR0 = 256 - (200 + 2) = 54.

#### Принцип роботи програми

Після ініціалізації портів та таймера програма записує в TMR0 значення 54.

Далі виконується очікування встановлення прапорця T0IF.

Коли таймер переповнюється, прапорець T0IF встановлюється в одиницю.

Після виявлення переповнення програма змінює стан виводу RB0 та повторює цикл підрахунку.

Для контролю переповнення використовується програмне опитування прапорця T0IF.

#### Очікуваний результат

- TMR0 працює від внутрішнього джерела тактування.
- Попередній дільник для TMR0 не використовується.
- Підрахунок 200 імпульсів відповідає інтервалу 200 мкс.
- При переповненні TMR0 встановлюється прапорець T0IF.
- Вивід RB0 змінює свій стан після виявлення переповнення.
