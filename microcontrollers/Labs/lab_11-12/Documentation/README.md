# Лабораторна робота №11–12

**Тема:** Використання модуля USART. Передача та прийом інформації.

**Дисципліна:** Мікроконтролери та їх програмування  
**Виконала:** Петращук Марія  
**Мікроконтролер:** PIC16F877A  
**Середовище розробки:** MPLAB X IDE v6.35, компілятор XC8  
**Середовище моделювання:** Proteus 8 Professional

## 1. Мета роботи

Навчитися використовувати модуль USART мікроконтролера PIC16F877A для асинхронного передавання та приймання інформації. Ознайомитися з налаштуванням послідовного інтерфейсу UART, передаванням ASCII-символів і роботою віртуальних терміналів у Proteus.

## 2. Завдання

1. Написати програму для роботи модуля USART в асинхронному режимі.
2. Виконати ініціалізацію портів мікроконтролера та модуля USART.
3. Налаштувати швидкість обміну 9600 бод, 8 біт даних, без парності, 1 стоповий біт.
4. Реалізувати передавання символів власного імені з використанням ASCII.
5. Реалізувати приймання даних із віртуального термінала.
6. Реалізувати режим Echo.
7. Організувати передавання інформації між двома віртуальними терміналами.

## 3. Теоретична частина

### 3.1. Інтерфейс UART

UART (Universal Asynchronous Receiver/Transmitter) — універсальний асинхронний прийомопередавач, призначений для послідовного обміну даними між електронними пристроями.

Під час асинхронного передавання використовується стартовий біт, інформаційні біти та стоповий біт. Окрема лінія тактового сигналу не потрібна.

### 3.2. Модуль USART

USART підтримує синхронний та асинхронний режими обміну даними.

Для роботи модуля використовуються регістри:

- **TXSTA** — керування передавачем.
- **RCSTA** — керування приймачем.
- **SPBRG** — налаштування швидкості обміну.
- **TXREG** — регістр переданих даних.
- **RCREG** — регістр прийнятих даних.
- **PIR1** — прапорці стану передавання та приймання.

У лабораторній роботі використано асинхронний режим USART зі швидкістю 9600 бод.

### 3.3. Розрахунок швидкості передавання

Для асинхронного високошвидкісного режиму використовується формула:

Baud Rate = Fosc / (16 × (SPBRG + 1))

За частоти генератора 4 МГц та значення SPBRG = 25 фактична швидкість становить приблизно 9615 бод, що близько до необхідних 9600 бод.

## 5. Хід виконання роботи

### 5.1. Створення проєкту

У середовищі MPLAB X IDE створено проєкт `Lab11_12_USART` для мікроконтролера PIC16F877A. Для програмування використано мову C та компілятор XC8.

У файлі `main.c` реалізовано ініціалізацію USART, функції передавання і приймання символів та три режими роботи програми.

Після компіляції отримано HEX-файл для моделювання в Proteus.

### 5.2. Передавання імені через USART

У першій частині програми реалізовано передавання символів імені `MARIIA` через інтерфейс UART.

Для передавання використано вихід RC6/TX мікроконтролера, підключений до входу RXD віртуального термінала.

У Proteus налаштовано швидкість 9600 бод, 8 біт даних, без парності та 1 стоповий біт.

**Результат:** після запуску симуляції у віртуальному терміналі періодично відображається текст `MARIIA`.

## 7. Відповіді на контрольні запитання

**1. Для чого призначений модуль UART?**

UART призначений для послідовного асинхронного передавання та приймання даних між пристроями.

**2. Які регістри використовуються для роботи модуля USART?**

Основні регістри: TXSTA, RCSTA, SPBRG, TXREG, RCREG та PIR1.

**3. Які особливості асинхронного обміну даними?**

Передавання здійснюється без окремого тактового сигналу. Для синхронізації використовуються стартовий і стоповий біти.

**4. Яким чином забезпечується однакова швидкість передавача та приймача?**

На обох пристроях встановлюється однакова швидкість передавання. У мікроконтролері вона налаштовується за допомогою регістра SPBRG і біта BRGH.

**5. Як працює USART у режимі асинхронного передавача?**

Програма записує байт у TXREG. Модуль USART автоматично формує послідовний кадр і передає його через TX.

**6. Як працює USART у режимі асинхронного приймача?**

Модуль USART приймає послідовні біти через RX, формує байт і записує його до RCREG для подальшого зчитування програмою.

**7. Яким чином можна поєднати TTL-рівні UART з рівнями RS232 ПК?**

Для перетворення електричних рівнів використовується спеціальний перетворювач, наприклад MAX232.

**8. Як визначити тривалість біта інформації при заданій швидкості в бодах?**

Тривалість біта обчислюється за формулою T = 1 / Baud Rate. Для 9600 бод вона становить приблизно 104,17 мкс.

**9. Для чого призначена функція putch(x)?**

Функція `putch(x)` використовується для передавання одного символу через налаштований канал виведення, наприклад UART.

**10. Яким чином передати дані із середовища Proteus у термінал PuTTY?**

Можна використати компонент COMPIM, підключений до COM-порту або пари віртуальних COM-портів. У PuTTY необхідно вибрати відповідний порт і встановити однакові параметри послідовного обміну.

**11. Для чого використовуються Esc-послідовності?**

Esc-послідовності використовуються для керування терміналом, зокрема очищення екрана, переміщення курсора та зміни параметрів відображення.

Під час виконання лабораторної роботи вивчено принципи роботи модуля USART мікроконтролера PIC16F877A. Реалізовано асинхронне передавання та приймання даних зі швидкістю 9600 бод.

За допомогою MPLAB X IDE та Proteus перевірено передавання ASCII-символів власного імені, приймання даних у режимі Echo та пересилання повідомлень між двома віртуальними терміналами.
