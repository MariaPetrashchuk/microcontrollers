**Тема:** Робота з протоколом 1-Wire. Налагодження програми «Термометр».

**Дисципліна:** Мікроконтролери та їх програмування

## 1. Мета роботи

Навчитися використовувати мікроконтролер PIC16F877A для обміну інформацією з цифровим датчиком температури DS18B20 через інтерфейс 1-Wire. Ознайомитися з принципами роботи протоколу, реалізувати передавання інформаційних байтів до пам'яті датчика та перевірити правильність запису в середовищі Proteus.

## 2. Завдання лабораторної роботи

1. Опрацювати теоретичний матеріал про протокол 1-Wire.
2. Описати основні функції для роботи з датчиком DS18B20.
3. Розробити програму для передавання трьох інформаційних байтів до SRAM датчика.
4. Записати значення до регістрів TH, TL та Configuration.
5. Відлагодити та скомпілювати програму в MPLAB X IDE.
6. Завантажити HEX-файл у Proteus.
7. Перевірити запис інформаційних байтів за адресами `02h`, `03h`, `04h`.
8. Реалізувати зчитування температури з датчика DS18B20.

## 3. Теоретична частина

### 3.1. Протокол 1-Wire

1-Wire — це послідовний протокол передавання даних, який використовує одну інформаційну лінію для обміну між ведучим і веденими пристроями.

Особливістю протоколу є використання підтягувального резистора, який забезпечує високий логічний рівень на шині у стані спокою.

Основні переваги 1-Wire:

- Невелика кількість провідників.
- Можливість підключення декількох пристроїв до однієї шини.
- Унікальна 64-бітна адреса кожного датчика.
- Простота використання в мікроконтролерних системах.

### 3.2. Датчик температури DS18B20

DS18B20 — цифровий датчик температури, який використовує протокол 1-Wire.

Основні характеристики:

- Діапазон вимірювання: від −55 °C до +125 °C.
- Програмована роздільна здатність: 9–12 біт.
- Точність: ±0,5 °C у діапазоні від −10 °C до +85 °C.
- Можливість зовнішнього або паразитного живлення.

Датчик має три контакти: GND, DQ та VDD.

### 3.3. Основні команди DS18B20

| Команда | Код | Призначення |
|---|---|---|
| Skip ROM | `0xCC` | Звернення до єдиного датчика на шині |
| Write Scratchpad | `0x4E` | Запис регістрів TH, TL і Configuration |
| Read Scratchpad | `0xBE` | Читання оперативної пам'яті |
| Convert T | `0x44` | Запуск вимірювання температури |

### 3.4. Пам'ять Scratchpad

Оперативна пам'ять DS18B20 містить регістри температури, порогових значень та конфігурації.

У лабораторній роботі використовуються:

| Адреса | Регістр | Значення |
|---|---|---|
| `02h` | TH | `1Eh` (30) |
| `03h` | TL | `0Ah` (10) |
| `04h` | Configuration | `7Fh` (12 біт) |

Запис виконується командою `0x4E`.

### 5.3. Реалізація протоколу 1-Wire

У програмі створено функції:

- `ow_low()` — встановлення низького рівня на шині.
- `ow_release()` — звільнення інформаційної лінії.
- `ow_reset()` — скидання шини та перевірка присутності датчика.
- `ow_write_bit()` — передавання одного біта.
- `ow_read_bit()` — приймання одного біта.
- `ow_write_byte()` — передавання байта.
- `ow_read_byte()` — приймання байта.

Передавання даних здійснюється починаючи з молодшого біта.

### 5.4. Запис інформаційних байтів

Для запису інформації використано команду `Write Scratchpad (0x4E)`.

Мікроконтролер передає послідовність:

`RESET → CC → 4E → 1E → 0A → 7F`

У результаті записуються три інформаційні байти:

- TH = 30 °C.
- TL = 10 °C.
- Configuration = `0x7F`.

### 5.5. Перевірка запису даних

Для перевірки використано команду `Read Scratchpad (0xBE)`.

Програма зчитує записані байти та порівнює їх із заданими значеннями.

За результатами перевірки отримано:

| Параметр | Значення |
|---|---|
| `sensor_present` | 1 |
| `write_verified` | 1 |
| `read_th` | 30 |
| `read_tl` | 10 |
| `read_config` | 127 |

Отримані значення відповідають переданим даним.

### 5.6. Вимірювання температури

Після налаштування датчика реалізовано запуск температурного перетворення командою `Convert T (0x44)`.

Програма очікує завершення перетворення, після чого зчитує два байти температури з пам'яті Scratchpad.

Результат зберігається у змінній `temperature_raw`.

Для 12-бітної роздільної здатності температура визначається за формулою:

**T = temperature_raw / 16**

Наприклад, для значення `temperature_raw = 400` температура становить 25 °C.

## 7. Відповіді на контрольні запитання

**1. Що таке протокол 1-Wire?**

1-Wire — це протокол послідовного обміну даними між пристроями через одну інформаційну лінію.

**2. Для чого потрібний підтягувальний резистор?**

Він забезпечує високий логічний рівень на шині, коли жоден пристрій не утримує її в низькому стані.

**3. Як здійснюється ініціалізація 1-Wire?**

Мікроконтролер формує імпульс скидання тривалістю приблизно 480 мкс, після чого очікує сигнал присутності датчика.

**4. Яке призначення команди Skip ROM?**

Команда `0xCC` дозволяє звернутися до датчика без зазначення його індивідуальної адреси. Її використовують, коли на шині є лише один датчик.

**5. Для чого використовується команда Write Scratchpad?**

Команда `0x4E` призначена для запису порогових значень TH, TL та регістра конфігурації датчика.

**6. Для чого призначена команда Read Scratchpad?**

Команда `0xBE` дозволяє зчитувати дані з оперативної пам'яті DS18B20.

**7. Яким чином змінюється роздільна здатність датчика?**

Роздільна здатність налаштовується через регістр Configuration і може становити 9, 10, 11 або 12 біт.

**8. Як отримати температуру з DS18B20?**

Потрібно запустити перетворення командою `0x44`, дочекатися його завершення та прочитати два байти температури з Scratchpad.
