# Лабораторна робота №2

**Тема:** Робота з портами вводу/виводу. Моделювання в Proteus VSM. Кодовий замок.

**Навчальна дисципліна:** Мікроконтролери та їх програмування

**Виконала:** Петращук Марія, група КН-33

## 1. Мета роботи

На прикладі мікроконтролера PIC16F84A вивчити режими роботи портів вводу/виводу, способи та особливості їх ініціалізації. Розглянути введення та виведення дискретних сигналів. Освоїти принципи побудови й симуляції електронних схем у середовищі Proteus VSM.

## 2. Завдання

1. Налагодити програму для роботи з портами мікроконтролера PIC16F84A.
2. Створити проєкт у MPLAB X IDE, відкомпілювати програмний код та отримати HEX-файл.
3. Створити в Proteus VSM схему з мікроконтролером PIC16F84A, вісьмома світлодіодами та двома перемикачами.
4. Підключити HEX-файл і перевірити роботу схеми відповідно до заданого алгоритму.
5. Розробити програму кодового замка з опитуванням клавіатури, перевіркою введеного коду та керуванням вихідними пристроями.
6. Провести моделювання роботи кодового замка в Proteus VSM.

## 3. Хід виконання роботи

### 3.1. Частина 1. Робота з портами вводу/виводу

Для виконання першої частини лабораторної роботи використовується мікроконтролер PIC16F84A.

Мікроконтролер має два порти вводу/виводу:

- **PORTA** — п'ятирозрядний порт, який використовується для приймання та передавання цифрових сигналів.
- **PORTB** — восьмирозрядний порт, який дозволяє керувати зовнішніми пристроями, зокрема світлодіодами.

Напрямок роботи виводів задається регістрами `TRISA` та `TRISB`. Значення 1 налаштовує вивід на введення, а 0 — на виведення.

### 3.2. Створення електронної схеми

У середовищі Proteus VSM передбачено створення електронної схеми з такими компонентами:

| Компонент | Кількість |
|---|---:|
| PIC16F84A | 1 |
| LED-YELLOW | 8 |
| Резистор 150 Ом | 8 |
| Резистор 10 кОм | 2 |
| Перемикач SWITCH | 2 |

Кнопка Кн1 підключається до виводу RA0, а кнопка Кн2 — до RA2. Світлодіоди підключаються до виводів RB0–RB7.

Для кнопок використовується підключення з підтягувальними резисторами. У ненатиснутому стані на вході присутня логічна одиниця, а під час натискання — логічний нуль.

У властивостях мікроконтролера необхідно вказати згенерований HEX-файл та встановити тактову частоту 4 МГц.

### 3.3. Ініціалізація портів

Для налаштування напрямку роботи портів використовуються такі команди:

```c
TRISA = 0b00011111;
TRISB = 0x00;
```

Регістр `TRISA` налаштовує лінії порту A на введення сигналів.

Регістр `TRISB` налаштовує всі вісім ліній порту B на виведення сигналів.

### 3.4. Алгоритм роботи програми

У програмі реалізується нескінченний цикл, у якому перевіряється стан двох кнопок.

Основна логіка програми:

```c
while (1)
{
    if (K1 == 0)
    {
        if (K2 == 0)
            PORTBbits.RB1 = 1;
        else
            PORTB = 0x3C;
    }
    else
    {
        if (K2 == 0)
            PORTB = 129;
        else
            PORTB = 0xFF;
    }
}
```

Залежно від стану кнопок на порт B виводяться різні значення, які визначають комбінацію ввімкнених світлодіодів.

### 3.5. Очікувані результати симуляції

| Кнопка Кн1 | Кнопка Кн2 | PORTB | Результат |
|---|---|---|---|
| Не натиснута | Не натиснута | 0xFF | Усі 8 світлодіодів |
| Не натиснута | Натиснута | 129 | RB7 та RB0 |
| Натиснута | Не натиснута | 0x3C | RB5, RB4, RB3, RB2 |
| Натиснута | Натиснута | RB1 = 1 | Встановлюється RB1, інші біти зберігають попередній стан |

За допомогою цієї програми можна дослідити роботу цифрових портів мікроконтролера та перевірити керування світлодіодами залежно від стану кнопок.

## 4. Частина 2. Розробка кодового замка

### 4.1. Принцип роботи кодового замка

У другій частині лабораторної роботи розглядається кодовий замок на основі мікроконтролера PIC16F84A.

Пристрій працює за принципом перевірки введеної користувачем кодової комбінації.

Мікроконтролер послідовно опитує кнопки клавіатури, зберігає введені значення та порівнює їх із кодом, записаним у пам'яті програми.

У разі правильного введення коду вмикається світлодіод, який сигналізує про успішну перевірку, та активується реле. Якщо код неправильний, вмикається інший світлодіод.

### 4.2. Підключення компонентів

Для керування кодовим замком використовуються такі виводи:

| Вивід | Призначення |
|---|---|
| RB3 | Кнопка Кн1 |
| RB2 | Кнопка Кн2 |
| RB1 | Кнопка Кн3 |
| RB0 | Кнопка Кн4 |
| RB4 | Кнопка OK |
| RB5 | Кнопка CLR |
| RA0 | Світлодіод правильного коду |
| RA1 | Світлодіод помилки |
| RA2 | Керування реле |

Кнопки підключаються з підтягувальними резисторами номіналом 10 кОм.

### 4.3. Алгоритм роботи кодового замка

Робота пристрою складається з таких етапів:

1. Мікроконтролер перевіряє стан кнопок Кн1–Кн4.
2. Після натискання кнопки програма очікує її відпускання.
3. Інформація про натискання зберігається в пам'яті.
4. Після натискання кнопки OK введена комбінація порівнюється зі збереженим кодом.
5. Якщо код правильний, активуються світлодіод RA0 та реле RA2.
6. Якщо код неправильний, активується світлодіод RA1.
7. Кнопка CLR очищає введені дані та вимикає виходи.

### 4.4. Формування кодової комбінації

Для збереження натискань використовується байтове представлення даних.

Старша тетрада містить порядковий номер натискання, а молодша — код натиснутої кнопки.

Коди кнопок:

- Кн1 — `0001`
- Кн2 — `0010`
- Кн3 — `0100`
- Кн4 — `1000`

У програмі передбачено перевірку PIN-коду `1223`.

```c
const unsigned char PIN_CODE[4] = {
    0x11, 0x22, 0x32, 0x44
};
```

Функція збереження натискань:

```c
static void add_key(unsigned char mask)
{
    if (count < MAX_LEN)
        entered[count] =
            (unsigned char)(((count + 1) << 4) | mask);

    if (count < 255)
        count++;
}
```

### 4.5. Перевірка введеного коду

Для перевірки правильності введеної комбінації використовується умовний оператор.

```c
if (codes_match())
{
    LED_OK = 1;
    LED_ERR = 0;
    RELAY = 1;
}
else
{
    LED_OK = 0;
    LED_ERR = 1;
    RELAY = 0;
}
```

Якщо введений код збігається зі збереженим, програма вмикає світлодіод правильного коду та реле.

У разі помилки вмикається світлодіод, який сигналізує про неправильну комбінацію.

### 4.6. Очікувані результати роботи кодового замка

| Дія користувача | Результат |
|---|---|
| Ввести 1, 2, 2, 3 та натиснути OK | Увімкнення RA0 та реле RA2 |
| Ввести неправильний код | Увімкнення RA1 |
| Натиснути CLR | Очищення введеного коду, вимкнення виходів |
| Ввести 1, 3, 2, 2 | Помилка через неправильний порядок введення |

Отже, програма повинна враховувати не лише натиснуті кнопки, але й порядок їх натискання.

## 5. Вихідний контроль

### 1. Яке призначення та функціональні особливості портів PIC16F8X?

Порти вводу/виводу забезпечують обмін інформацією між мікроконтролером і зовнішніми пристроями.

PORTA має п'ять розрядів, а PORTB — вісім. Кожен вивід можна окремо налаштувати на введення або виведення даних. Порт B також підтримує внутрішні підтягувальні резистори та переривання при зміні сигналів на RB4–RB7.

### 2. Для чого призначені регістри TRISA, TRISB, PORTA та PORTB?

Регістри TRISA та TRISB визначають напрямок роботи виводів портів. Значення 1 відповідає режиму введення, а 0 — режиму виведення.

Регістри PORTA та PORTB використовуються для зчитування цифрових сигналів і керування вихідними станами портів.

### 3. Як відбувається процес модифікації біта порту?

Модифікація виконується за принципом «читання — зміна — запис». Спочатку зчитується поточний стан порту, потім змінюється необхідний біт, після чого оновлене значення записується назад.

### 4. Як відбувається опитування стану кнопки?

Кнопка підключається до входу мікроконтролера з використанням підтягувального резистора.

У ненатиснутому стані на вході присутній логічний рівень 1, а після натискання — 0.

Програма перевіряє стан входу за допомогою умовного оператора `if`.

### 5. Як створити проєкт на основі мікроконтролера у Proteus VSM?

Необхідно створити новий проєкт, додати мікроконтролер та інші електронні компоненти з бібліотеки, розмістити їх на робочому полі й з'єднати відповідно до схеми.

Після цього у властивостях мікроконтролера потрібно вибрати HEX-файл, налаштувати тактову частоту та запустити симуляцію.

### 6. Як працює типовий кодовий замок на основі мікроконтролера?

Мікроконтролер опитує клавіатуру, приймає введений код і порівнює його зі збереженим у пам'яті.

Якщо комбінація правильна, формується сигнал для відкривання замка. Якщо неправильна — доступ не надається.

### 7. Як працює досліджуваний кодовий замок?

Кодовий замок працює в режимі охорони.

Користувач вводить код кнопками Кн1–Кн4 та підтверджує його кнопкою OK.

Якщо код правильний, вмикається світлодіод RA0 і реле RA2. Якщо неправильний — світлодіод RA1.

Кнопка CLR призначена для очищення введеної комбінації.

### 8. Яка особливість опитування кнопок клавіатури кодового замка?

Програма послідовно перевіряє кнопки клавіатури та очікує відпускання кожної натиснутої кнопки.

Це дозволяє уникнути багаторазового врахування одного натискання.

Кожне натискання зберігається разом із його порядковим номером, тому порядок введення цифр впливає на результат перевірки коду.
