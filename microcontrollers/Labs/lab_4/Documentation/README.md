
# Лабораторна робота №4

## Тема
Налагодження програми динамічної індикації.

## Мета роботи
Вивчити способи формування сигналів керування та індикації на прикладі мікроконтролера PIC16F84A, розглянути використання динамічної індикації.

## Завдання

### Частина 1. Динамічна індикація

1. Розробити та налагодити програму виведення інформації на семисегментний індикатор із використанням динамічної індикації.
2. На дворозрядному семисегментному індикаторі відобразити число дня свого народження.
3. Забезпечити перемикання розрядів індикатора з часовим інтервалом 10–20 мс.
4. Розробити, налагодити та скомпілювати керуючу програму в MPLAB.
5. Перевірити часові інтервали перемикання розрядів програмним секундоміром MPLAB.
6. Завантажити отриманий HEX-файл у симулятор Proteus.
7. Перевірити роботу схеми відповідно до завдання.

### Частина 2. Матрична клавіатура

1. Розробити програму сканування матричної клавіатури.
2. Реалізувати визначення натиснутої кнопки.
3. Вивести відповідний символ на семисегментний індикатор.
4. Налагодити програму в MPLAB.
5. Завантажити HEX-файл у Proteus.
6. Перевірити роботу схеми кодового замка.

## Використані засоби

- Мікроконтролер PIC16F84A.
- MPLAB X IDE v6.35.
- Компілятор MPLAB XC8 v3.10.
- MPLAB Simulator.
- Proteus 8 Professional.
- Мова програмування C.

## Теоретичні відомості

### Семисегментний індикатор

Семисегментний індикатор — це електронний пристрій для відображення цифр від 0 до 9.

Він складається із семи світлодіодних сегментів, позначених літерами a, b, c, d, e, f, g, а також може містити сегмент десяткової крапки DP.

Для відображення цифри необхідно увімкнути відповідну комбінацію сегментів.

### Статична індикація

Статична індикація — це спосіб відображення інформації, за якого необхідні сегменти індикатора постійно перебувають у ввімкненому стані.

Перевагою є простота реалізації, а недоліком — необхідність використання більшої кількості виводів мікроконтролера для багаторозрядних індикаторів.

### Динамічна індикація

Динамічна індикація — це спосіб відображення інформації, за якого розряди індикатора вмикаються почергово.

Мікроконтролер послідовно подає коди цифр на спільні сегментні лінії та активує потрібний розряд.

Завдяки швидкому перемиканню людське око сприймає інформацію як одночасне світіння всіх розрядів.

Основні переваги:
- Зменшення кількості необхідних виводів мікроконтролера.
- Спрощення схеми підключення.
- Можливість керування багаторозрядними індикаторами.

### Матрична клавіатура

Матрична клавіатура складається з рядків і стовпців, на перетині яких розташовані кнопки.

Для визначення натиснутої кнопки мікроконтролер послідовно сканує стовпці та зчитує сигнали з рядків.

Цей спосіб дозволяє підключати велику кількість кнопок, використовуючи відносно невелику кількість виводів мікроконтролера.
