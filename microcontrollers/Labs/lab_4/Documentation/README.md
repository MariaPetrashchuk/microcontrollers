
# Лабораторна робота №4

## Тема
Налагодження програми динамічної індикації.

## Мета роботи
Вивчити способи формування сигналів керування та індикації на прикладі мікроконтролера PIC16F84A, розглянути використання динамічної індикації.

## Обладнання та програмне забезпечення
- Мікроконтролер PIC16F84A.
- Дворозрядний семисегментний індикатор.
- MPLAB X IDE v6.35.
- Компілятор MPLAB XC8 v3.10.
- MPLAB Simulator.
- Proteus 8 Professional.
- Мова програмування C.

## Завдання

1. Розробити програму виведення інформації на семисегментний індикатор із використанням динамічної індикації.
2. Відобразити на дворозрядному семисегментному індикаторі число дня свого народження.
3. Забезпечити часовий інтервал перемикання розрядів 10–20 мс.
4. Розробити та скомпілювати програму в MPLAB.
5. Перевірити часові інтервали перемикання розрядів за допомогою програмного секундоміра MPLAB.
6. Завантажити HEX-файл у Proteus.
7. Перевірити роботу схеми динамічної індикації.
8. Розробити програму сканування матричної клавіатури з відображенням символів на семисегментному індикаторі.

## Теоретичні відомості

### Семисегментний індикатор

Семисегментний індикатор — це електронний пристрій, призначений для відображення цифрової інформації.

Він складається із семи світлодіодних сегментів, позначених літерами a, b, c, d, e, f, g. Додатково індикатор може містити десяткову крапку DP.

Для відображення певної цифри необхідно ввімкнути відповідну комбінацію сегментів.

### Статична індикація

Статична індикація — це спосіб відображення інформації, за якого необхідні сегменти індикатора світяться безперервно.

Перевагою цього способу є простота керування, а недоліком — необхідність використання більшої кількості виводів мікроконтролера.

### Динамічна індикація

Динамічна індикація — це спосіб відображення інформації, за якого окремі розряди індикатора вмикаються почергово.

Мікроконтролер послідовно передає коди цифр на спільні сегментні лінії та активує потрібний розряд.

Завдяки швидкому перемиканню людське око сприймає всі розряди як одночасно ввімкнені.

Основні переваги динамічної індикації:
- Зменшення кількості необхідних виводів мікроконтролера.
- Спрощення схеми підключення.
- Можливість керування багаторозрядними індикаторами.

### Матрична клавіатура

Матрична клавіатура складається з рядків і стовпців, на перетині яких розташовані кнопки.

Для визначення натиснутої кнопки мікроконтролер послідовно активує стовпці та зчитує стан рядків.

Такий спосіб дозволяє підключити велику кількість кнопок, використовуючи відносно невелику кількість виводів мікроконтролера.


## Хід виконання роботи

### Завдання 1. Динамічна індикація

Було розроблено програму динамічної індикації для мікроконтролера PIC16F84A.

Відповідно до індивідуального завдання на дворозрядному семисегментному індикаторі необхідно відобразити число дня народження — 03.

Для керування сегментами індикатора використовується порт PORTB, а для перемикання розрядів — виводи RA2 та RA3.

Програма почергово виводить цифри 0 та 3 із затримкою 10 мс для кожного розряду.

Очікувана тривалість повного циклу становить приблизно 20 мс, що відповідає частоті оновлення близько 50 Гц.

Програму реалізовано мовою C для компілятора MPLAB XC8.


### Розробка та компіляція програми

Для реалізації динамічної індикації було розроблено програму мовою C для мікроконтролера PIC16F84A.

Програма призначена для відображення числа дня народження — 03 — на дворозрядному семисегментному індикаторі.

Розробку виконано для середовища MPLAB X IDE v6.35 із використанням компілятора MPLAB XC8 v3.10.

Параметри проєкту:
- Мікроконтролер: PIC16F84A.
- Тактова частота: 4 МГц.
- Тип генератора: XT.
- Мова програмування: C.
- Компілятор: MPLAB XC8 v3.10.

У програмі реалізовано почергове відображення цифр 0 та 3.

Для керування сегментами використовується порт PORTB, а для перемикання розрядів — виводи RA2 та RA3.

Тривалість увімкнення кожного розряду задана програмною затримкою 10 мс.

Після успішної компіляції створюється HEX-файл для подальшого моделювання в Proteus.


### Моделювання динамічної індикації в Proteus

Для перевірки роботи програми використано середовище Proteus 8 Professional.

Було підготовлено електричну схему, що містить мікроконтролер PIC16F84A, дворозрядний семисегментний індикатор 7SEG-MPX2-CC, струмообмежувальні резистори та два NPN-транзистори.

Для керування сегментами індикатора використовується порт PORTB, а для вибору активного розряду — виводи RA2 та RA3.

Програма призначена для відображення числа дня народження — 03.

Частота тактування мікроконтролера становить 4 МГц.

Очікувана тривалість увімкнення кожного розряду — приблизно 10 мс.

Очікувана тривалість повного циклу індикації — приблизно 20 мс.


### Перевірка часових інтервалів у MPLAB Simulator

Для перевірки часових інтервалів динамічної індикації передбачено використання програмного секундоміра MPLAB Simulator.

Програма реалізує почергове ввімкнення двох розрядів семисегментного індикатора для відображення числа 03.

Для формування часових інтервалів використовується функція `__delay_ms(10)`.

Тактова частота мікроконтролера становить 4 МГц.

Тривалість одного машинного циклу:

Tц = 4 / 4 000 000 = 1 мкс.

Розрахункові часові параметри:
- Тривалість увімкнення першого розряду — приблизно 10 мс.
- Тривалість увімкнення другого розряду — приблизно 10 мс.
- Повний цикл динамічної індикації — приблизно 20 мс.
- Частота оновлення індикатора — приблизно 50 Гц.

Фактичні результати вимірювання програмним секундоміром:

- Перший розряд: [вказати результат] мс.
- Другий розряд: [вказати результат] мс.
- Повний цикл: [вказати результат] мс.

Отримані значення необхідно порівняти з розрахунковими для підтвердження правильності формування часових інтервалів.


### Частина 2. Сканування матричної клавіатури

У другій частині лабораторної роботи розроблено програму сканування матричної клавіатури 3×4 для мікроконтролера PIC16F84A.

Для сканування клавіатури використовується порт PORTB.

Виводи RB0–RB2 призначені для почергового активування стовпців клавіатури, а RB4–RB7 — для зчитування станів рядків.

Програма послідовно перевіряє стан кожного стовпця та визначає натиснуту кнопку за відповідним рядком.

Для усунення брязкоту контактів використовується програмна затримка 20 мс.

Після визначення натиснутої клавіші її чотирибітний код передається через PORTA на дешифратор семисегментного індикатора.

Для цифрових клавіш передаються коди від 0 до 9, а для клавіш "*" та "#" — коди E та F відповідно.

Очікуваний результат — визначення натиснутої кнопки та відображення відповідного символу на семисегментному індикаторі.


### Моделювання матричної клавіатури в Proteus

Для перевірки роботи програми сканування матричної клавіатури підготовлено схему в середовищі Proteus 8 Professional.

Схема містить:
- Мікроконтролер PIC16F84A.
- Матричну клавіатуру 3×4.
- Дешифратор CD4511.
- Семисегментний індикатор зі спільним катодом.
- Струмообмежувальні та підтягувальні резистори.

Для сканування клавіатури використовуються виводи RB0–RB2 та RB4–RB7.

Для передавання чотирибітного коду натиснутої клавіші використовуються виводи RA0–RA3.

Програма послідовно активує стовпці клавіатури та зчитує стан рядків.

Після визначення натиснутої кнопки відповідний код передається на дешифратор CD4511, який керує семисегментним індикатором.

Очікуваний результат — відображення цифр від 0 до 9 відповідно до натиснутої клавіші.

## Контрольні запитання

### 1. Що таке динамічна індикація?

Динамічна індикація — це спосіб відображення інформації, за якого окремі розряди індикатора вмикаються почергово з великою частотою.

Завдяки інерційності людського зору створюється враження одночасного світіння всіх розрядів.

### 2. Чим відрізняється статична індикація від динамічної?

При статичній індикації необхідні сегменти світяться постійно.

При динамічній індикації розряди вмикаються почергово, використовуючи спільні лінії керування сегментами.

Динамічна індикація дозволяє зменшити кількість виводів мікроконтролера, необхідних для керування багаторозрядним індикатором.

### 3. Для чого використовуються семисегментні індикатори?

Семисегментні індикатори використовуються для відображення цифрової інформації.

Вони застосовуються в електронних годинниках, вимірювальних приладах, лічильниках та інших електронних пристроях.

### 4. Яку функцію виконує порт PORTB у розробленій програмі?

У програмі динамічної індикації порт PORTB використовується для передавання кодів цифр на сегменти індикатора.

Кожна комбінація бітів визначає, які сегменти необхідно ввімкнути для відображення відповідної цифри.

### 5. Для чого використовуються виводи RA2 та RA3?

Виводи RA2 та RA3 використовуються для керування транзисторами, які почергово активують два розряди семисегментного індикатора.

RA2 відповідає за перший розряд, а RA3 — за другий.

### 6. Для чого потрібна затримка під час динамічної індикації?

Затримка визначає тривалість увімкнення кожного розряду індикатора.

Правильно підібраний часовий інтервал забезпечує стабільне сприйняття інформації без помітного мерехтіння.

### 7. Що таке матрична клавіатура?

Матрична клавіатура — це пристрій введення інформації, кнопки якого розташовані на перетинах рядків і стовпців.

Таке підключення дозволяє зменшити кількість необхідних виводів мікроконтролера.

### 8. Як здійснюється сканування матричної клавіатури?

Мікроконтролер почергово активує стовпці клавіатури та перевіряє стани рядків.

За комбінацією активного стовпця та рядка визначається натиснута кнопка.

### 9. Для чого використовується програмне усунення брязкоту контактів?

Під час натискання механічної кнопки контакти можуть багаторазово замикатися та розмикатися протягом короткого часу.

Програмна затримка та повторна перевірка стану кнопки дозволяють уникнути помилкового визначення декількох натискань.

### 10. Яке призначення дешифратора CD4511?

CD4511 перетворює чотирибітний двійково-десятковий код у сигнали керування семисегментним індикатором зі спільним катодом.

Він дозволяє відображати десяткові цифри від 0 до 9.


## Висновок

Під час виконання лабораторної роботи №4 було вивчено принципи формування сигналів керування семисегментними індикаторами на прикладі мікроконтролера PIC16F84A.

Розглянуто особливості статичної та динамічної індикації, їхні переваги та відмінності.

У першій частині роботи розроблено програму для відображення числа дня народження — 03 — на дворозрядному семисегментному індикаторі. Для керування сегментами використано порт PORTB, а для перемикання розрядів — виводи RA2 та RA3. Розрахункова тривалість увімкнення кожного розряду становить приблизно 10 мс.

У другій частині роботи розроблено програму сканування матричної клавіатури 3×4 із визначенням натиснутої кнопки та передаванням її коду для відображення на семисегментному індикаторі.

У процесі роботи було опрацьовано налаштування портів введення/виведення, використання програмних затримок, принципи сканування клавіатури та формування сигналів керування індикаторами.

Таким чином, було закріплено теоретичні знання щодо організації введення та відображення інформації в мікроконтролерних системах.
