## 3. Теоретична частина

### 3.1. Призначення РКІ

Рідкокристалічний індикатор (РКІ) — електронний пристрій для відображення текстової та цифрової інформації.

Знакосимвольні РКІ застосовуються в мікроконтролерних системах для виведення повідомлень, параметрів роботи, результатів вимірювань і пунктів меню.

### 3.2. Принцип роботи

Мікроконтролер передає до РКІ команди керування та коди символів. Контролер дисплея обробляє отриману інформацію та забезпечує її відображення.

Для обміну даними можуть використовуватися чотирибітний або восьмибітний інтерфейси.

У лабораторній роботі використовується восьмибітний режим.

### 3.3. Інтерфейс РКІ

Основні сигнали:

- DB0–DB7 — восьмибітна шина даних.
- RS — вибір регістра команд або даних.
- R/W — вибір режиму читання або запису.
- E — сигнал дозволу передавання інформації.

При RS = 0 передаються команди, при RS = 1 — дані.

При R/W = 0 виконується запис, при R/W = 1 — читання.

### 3.4. Ініціалізація РКІ

Перед виведенням тексту потрібно налаштувати режим роботи дисплея.

Основні команди:

| Команда | Призначення |
|---------|-------------|
| 0x38 | Восьмибітний режим, два рядки, символи 5×8 |
| 0x08 | Вимкнення дисплея |
| 0x0C | Увімкнення дисплея без курсора |
| 0x0F | Увімкнення дисплея з курсором і мерехтінням |
| 0x01 | Очищення дисплея |
| 0x06 | Автоматичне переміщення курсора вправо |
| 0x80 | Початок першого рядка |
| 0xC0 | Початок другого рядка |

### 3.5. Пам'ять РКІ

У рідкокристалічному індикаторі використовуються:

- DDRAM — пам'ять символів, які виводяться на дисплей.
- CGROM — постійна пам'ять стандартних символів.
- CGRAM — пам'ять користувацьких символів.

### 3.6. Матрична клавіатура

Матрична клавіатура складається з рядків і стовпців.

Для визначення натиснутої кнопки мікроконтролер послідовно активує рядки та зчитує стан стовпців.

За знайденою комбінацією рядка і стовпця визначається символ натиснутої кнопки.

Для уникнення помилкових повторних натискань застосовується програмне усунення брязкоту контактів.

### 3.7. Організація меню

Меню дозволяє користувачу вибирати режими роботи пристрою.

Для керування застосовуються кнопки:

- UP — переміщення вгору.
- DOWN — переміщення вниз.
- OK — підтвердження вибору.
- ESC — повернення на попередній рівень.

Поточний пункт меню позначається символом `>`.

### 4.2. Налаштування портів

Для керування індикатором використано PORTB та PORTD.

Підключення:

| PIC16F877A | РКІ |
|------------|-----|
| RB0 | RS |
| RB1 | R/W |
| RB2 | E |
| RD0–RD7 | DB0–DB7 |

Контакти RB0–RB2 налаштовано як виходи керування.

Усі контакти PORTD налаштовано як виходи для передавання восьмибітних даних.

## 6. Тема 3. Організація меню на РКІ

### 6.1. Завдання

Реалізувати систему меню з використанням чотирьох кнопок керування.

Передбачити вибір двох команд:

- OPEN — відкриття воріт.
- CLOSE — закриття воріт.

### 6.2. Принцип роботи меню

Після запуску пристрою на РКІ виводиться стартове запрошення.

Натискання кнопки OK відкриває головне меню.

Кнопками UP і DOWN користувач переміщує покажчик вибору.

Кнопка OK підтверджує вибраний пункт.

Кнопка ESC повертає користувача до попереднього рівня меню.

### 6.3. Алгоритм роботи меню

1. Запуск мікроконтролера.
2. Ініціалізація РКІ та портів.
3. Відображення стартового запрошення.
4. Очікування натискання OK.
5. Відкриття головного меню.
6. Опитування кнопок UP, DOWN, OK та ESC.
7. Вибір пункту OPEN або CLOSE.
8. Збереження вибору у прапорці FLAG.
9. Підтвердження вибору кнопкою OK.
10. Виконання відповідної дії.
11. Відображення стану OPENED або CLOSED.
12. Повернення до меню після натискання ESC.

### 6.4. Вибір пункту меню

При виборі OPEN:

```text
+----------------+
|>OPEN           |
| CLOSE          |
+----------------+
```

При виборі CLOSE:

```text
+----------------+
| OPEN           |
|>CLOSE          |
+----------------+
```

### 6.5. Виконання команд

При виборі OPEN система повинна:

1. Встановити FLAG = 0.
2. Активувати команду відкриття воріт.
3. Увімкнути зелений світлодіод.
4. Відобразити стан OPENED.

При виборі CLOSE система повинна:

1. Встановити FLAG = 1.
2. Активувати команду закриття воріт.
3. Увімкнути червоний світлодіод.
4. Відобразити стан CLOSED.

При натисканні ESC система повинна вийти з меню керування та скинути прапорець вибору.

### 6.6. Очікуваний результат

Меню повинно забезпечувати переміщення між пунктами, підтвердження вибору та відображення стану пристрою.

Для підтвердження виконання теми необхідно створити окрему програму керування меню й перевірити роботу кнопок та індикації в Proteus.

## 7. Відповіді на контрольні питання до теми 1

### 1. Призначення модуля РКІ

Модуль РКІ призначений для відображення текстової, цифрової та символьної інформації в електронних пристроях.

### 2. Запишіть порядок роботи інтерфейсу обміну

Спочатку встановлюються сигнали RS і R/W, потім дані на шину DB0–DB7. Після цього формується імпульс E, який забезпечує приймання інформації контролером РКІ.

### 3. Який формат має команда модуля?

У восьмибітному режимі команда передається одним байтом. Її біти визначають необхідну операцію: очищення екрана, налаштування режиму, керування курсором або встановлення адреси пам'яті.

### 4. Як відбувається управління модулем РКІ?

Управління здійснюється передаванням команд і даних через інформаційну шину та керуючі сигнали RS, R/W і E.

### 5. Які типи пам'яті має РКІ та їх призначення?

DDRAM зберігає символи, які відображаються на дисплеї. CGROM містить стандартні зображення символів. CGRAM використовується для створення власних символів.

### 6. Призначення області DD-RAM

DDRAM використовується для збереження кодів символів, що відображаються на екрані РКІ.

### 7. Призначення області CGROM

CGROM містить стандартний набір символів, зокрема латинські літери, цифри та спеціальні знаки.

### 8. За якими адресами виводяться символи?

У типовому дворядковому РКІ на базі HD44780 перший рядок починається з адреси DDRAM 0x00, другий — з 0x40.

Для встановлення курсора на початок рядків передаються команди 0x80 і 0xC0 відповідно.

### 9. Як задається режим індикації символу?

Режим індикації налаштовується командами керування дисплеєм, які визначають стан екрана, курсора та його мерехтіння.

### 10. Скільки символів можна вивести на дворядкове табло?

На типовому дворядковому індикаторі 16×2 одночасно відображаються 32 символи — по 16 у кожному рядку.

## 8. Відповіді на контрольні питання до тем 2 та 3

### 1. Яким чином здійснюється опитування кнопки?

Мікроконтролер періодично зчитує стан відповідного входу. Для матричної клавіатури застосовується послідовне сканування рядків і стовпців.

### 2. Яким чином забезпечується однозначне виявлення події натискання кнопки?

Для цього використовується програмне усунення брязкоту контактів та контроль переходу кнопки зі стану «відпущена» у стан «натиснута».

### 3. Як здійснюється обробка події натискання кнопки?

Після виявлення натискання програма визначає кнопку та виконує відповідну дію: виведення символу, зміну пункту меню або підтвердження команди.

### 4. Яким чином можна реалізувати навігацію по меню?

Навігація реалізується кнопками UP і DOWN, які змінюють вибраний пункт. Кнопка OK підтверджує вибір, а ESC забезпечує повернення.

### 5. Якими засобами можна керувати з використанням даного меню?

За допомогою меню можна керувати електродвигунами, воротами, освітленням, реле, сигналізацією та іншими електронними пристроями.

### 6. Які обмеження присутні на використання операторів безумовного переходу?

Оператор goto передає керування до мітки в межах тієї самої функції.

Надмірне використання goto ускладнює читання, тестування та налагодження програми. Тому для реалізації меню доцільніше використовувати цикли, умовні оператори та конструкцію switch-case.

## 9. Аналіз результатів

Для першої теми підготовлено програму керування знакосимвольним РКІ на базі PIC16F877A.

У програмі реалізовано налаштування портів, ініціалізацію дисплея, передавання команд і символів та виведення імені й прізвища латинськими літерами.

Для другої теми розглянуто алгоритм сканування матричної клавіатури та виведення символів натиснутих кнопок на РКІ.

Для третьої теми описано організацію меню з командами OPEN і CLOSE, навігацією кнопками та індикацією стану системи.

Фактичні результати компіляції, налагодження й моделювання необхідно підтвердити після перевірки відповідних програм у MPLAB X IDE та Proteus.

## 10. Висновок

Під час виконання лабораторної роботи №7–8 розглянуто принципи керування алфавітно-символьними рідкокристалічними індикаторами за допомогою мікроконтролера PIC16F877A.

Опрацьовано особливості восьмибітного інтерфейсу, призначення керуючих сигналів RS, R/W та E, порядок ініціалізації РКІ та передавання символів.

Розроблено програмний код для виведення імені та прізвища латинськими літерами.

Також розглянуто принципи сканування матричної клавіатури, обробки натискання кнопок та організації багаторівневого керування за допомогою меню.

Отримані знання можуть використовуватися для створення мікроконтролерних систем із текстовим інтерфейсом користувача.
