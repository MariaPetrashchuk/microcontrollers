
# Лабораторна робота №7–8

**Тема:** Керування алфавітно-символьним РКІ.

**Дисципліна:** Мікроконтролери та їх програмування.

**Мікроконтролер:** PIC16F877A.

**Тактова частота:** 4 МГц.

## Мета роботи

Навчитись застосовувати мікроконтролери для схемотехнічних рішень. Використовуючи принципову схему пристрою, скласти програму, що керуватиме роботою рідкокристалічного індикатора.

## Завдання лабораторної роботи

1. Написати керуючу програму для мікроконтролера PIC16F877A для керування модулем знакосимвольного рідкокристалічного індикатора.

2. Створити проєкт у середовищі MPLAB.

3. Задати необхідні параметри конфігурації мікроконтролера для роботи з тактовою частотою Fosc = 4 МГц.

4. Провести ініціалізацію портів мікроконтролера відповідно до принципової схеми.

5. Написати основні функції для передачі команд і даних до РКІ.

6. Реалізувати ініціалізацію рідкокристалічного індикатора з використанням восьмибітного інтерфейсу.

7. Використовуючи символи ASCII, реалізувати відображення власного імені та прізвища латинськими літерами.

8. Виконати налагодження програми в середовищі MPLAB.

9. Завантажити отриманий HEX-файл у мікроконтролер у середовищі Proteus.

10. Перевірити правильність роботи створеного пристрою.

## Теоретична частина

### 1. Призначення рідкокристалічного індикатора

Рідкокристалічний індикатор (РКІ) — електронний пристрій, призначений для відображення текстової та цифрової інформації.

Знакосимвольні РКІ використовуються в електронних пристроях для відображення повідомлень, параметрів роботи та результатів вимірювань.

Основою РКІ є матриця рідких кристалів, роботою якої керує вбудований контролер.

### 2. Будова РКІ

Рідкокристалічний індикатор складається з:

- Рідкокристалічної матриці.
- Вбудованого контролера.
- Пам'яті символів.
- Інтерфейсу для обміну даними з мікроконтролером.
- Системи живлення та керування контрастністю.

Символи формуються за допомогою матриці точок, найчастіше розміром 5×8.

РКІ можуть мати один, два або чотири рядки для відображення інформації.

### 3. Принцип роботи РКІ

Мікроконтролер передає до РКІ команди керування та коди символів.

Вбудований контролер РКІ приймає інформацію, обробляє її та забезпечує відображення відповідних символів на екрані.

Для передавання інформації використовується паралельний інтерфейс.

У лабораторній роботі використовується восьмибітний режим обміну даними.

### 4. Інтерфейс РКІ

РКІ має інформаційні та керуючі лінії.

Основні сигнали:

- DB0–DB7 — восьмибітна шина передачі даних.
- RS — вибір регістра команд або даних.
- R/W — вибір режиму читання або запису.
- E — сигнал дозволу передачі інформації.

Призначення керуючих сигналів:

RS = 0 — передача команди.

RS = 1 — передача даних.

R/W = 0 — запис інформації до РКІ.

R/W = 1 — читання інформації з РКІ.

Сигнал E використовується для формування імпульсу, під час якого контролер РКІ приймає інформацію.

### 5. Порядок передачі інформації

Для запису команди або символу необхідно:

1. Встановити значення сигналу RS.
2. Встановити R/W = 0.
3. Передати восьмибітне значення на лінії DB0–DB7.
4. Сформувати імпульс на вході E.
5. Дочекатися завершення обробки інформації контролером РКІ.

### 6. Ініціалізація РКІ

Перед початком роботи необхідно виконати ініціалізацію індикатора.

Основні команди:

- 0x38 — восьмибітний режим, два рядки, символи 5×8.
- 0x0F — увімкнення дисплея, курсора та мерехтіння.
- 0x01 — очищення дисплея.
- 0x06 — автоматичне переміщення курсора вправо.

Після подачі живлення необхідно витримати початкову затримку, а між командами — паузи, достатні для їх виконання.

### 7. Пам'ять РКІ

Рідкокристалічний індикатор використовує три основні області пам'яті:

DDRAM — пам'ять символів, що відображаються на екрані.

CGROM — постійна пам'ять стандартних символів.

CGRAM — пам'ять для створення власних символів користувача.

Для встановлення позиції курсора використовується команда запису адреси DDRAM.

### 8. Відображення символів ASCII

ASCII — система кодування, у якій кожному символу відповідає числовий код.

Для відображення символу мікроконтролер передає відповідний код до контролера РКІ.

Наприклад:

- A — 0x41.
- B — 0x42.
- M — 0x4D.
- P — 0x50.

Для відображення імені та прізвища латинськими літерами необхідно послідовно передати коди відповідних символів.

### 9. Використання мікроконтролера PIC16F877A

PIC16F877A — восьмибітний мікроконтролер, який має цифрові порти введення-виведення та вбудовані периферійні модулі.

У лабораторній роботі він використовується для керування рідкокристалічним індикатором.

Мікроконтролер виконує ініціалізацію портів, передає команди керування та забезпечує відображення текстової інформації.

Тактова частота мікроконтролера становить 4 МГц.
