
# Лабораторна робота №3

**Тема:** Формування часових інтервалів. Використання секундоміра MPLAB.

**Навчальна дисципліна:** Мікроконтролери та їх програмування

**Виконала:** Петращук Марія

## 1. Мета роботи

Навчитись застосовувати мікроконтролери для схемотехнічних рішень. Використовуючи принципову схему пристрою, скласти програму, що генеруватиме електричні коливання.

## 2. Завдання

1. Розробити програму генерації електричних коливань із використанням часових затримок.
2. Сформувати на виводі RB4 мікроконтролера PIC16F84A імпульси з частотою 5 кГц.
3. Розрахувати тривалість імпульсів для коефіцієнтів заповнення 10% і 90%.
4. Дослідити роботу програми в MPLAB X IDE за допомогою Simulator і секундоміра.
5. Створити електронну схему в Proteus VSM.
6. Перевірити форму сигналу за допомогою віртуального осцилографа.
7. Реалізувати програмне керування ШІМ на виводі RB0 за допомогою двох кнопок.

## 3. Розрахунок часових інтервалів

Для генерації імпульсів на виводі RB4 мікроконтролера PIC16F84A задано частоту F = 5 кГц.

Період сигналу:

T = 1 / F = 1 / 5000 = 0,0002 с = 200 мкс.

Коефіцієнт заповнення визначається формулою:

D = τ / T,

де τ — тривалість високого рівня сигналу, T — період.

### Варіант 1. Коефіцієнт заповнення 10%

τ = 200 × 0,1 = 20 мкс.

Тривалість низького рівня: 200 − 20 = 180 мкс.

Шпарність: S = 1 / 0,1 = 10.

### Варіант 2. Коефіцієнт заповнення 90%

τ = 200 × 0,9 = 180 мкс.

Тривалість низького рівня: 200 − 180 = 20 мкс.

Шпарність: S = 1 / 0,9 ≈ 1,11.

## 4. Очікувані результати

На виводі RB4 має формуватися періодичний сигнал із частотою приблизно 5 кГц. Для коефіцієнта заповнення 10% високий рівень триває 20 мкс, низький — 180 мкс. Для 90% високий рівень триває 180 мкс, низький — 20 мкс.

Фактичні параметри сигналу необхідно перевірити в MPLAB X IDE та Proteus VSM.


## 5. Хід виконання роботи

### 5.1. Створення проєкту в MPLAB X IDE

Для виконання лабораторної роботи підготовлено програмний код для мікроконтролера PIC16F84A з використанням компілятора XC8. Передбачено тактову частоту 4 МГц та використання програмного симулятора MPLAB.

### 5.2. Генерація імпульсів

У файлі `main.c` реалізовано програму формування імпульсів на виводі RB4 із цільовим коефіцієнтом заповнення 10%. Високий рівень формується із затримкою 20 мкс, низький — 180 мкс.

У файлі `pulse_90.c` реалізовано аналогічну програму з цільовим коефіцієнтом заповнення 90%. Для високого рівня задано 180 мкс, для низького — 20 мкс.

### 5.3. Програмне керування ШІМ

У файлі `pwm_control.c` реалізовано навчальний алгоритм керування коефіцієнтом заповнення ШІМ-сигналу на виводі RB0.

Кнопка RB1 збільшує коефіцієнт заповнення, а кнопка RB2 зменшує його.

Початкове значення становить 50%, діапазон регулювання — від 10% до 90%.

### 5.4. Перевірка часових інтервалів

Для перевірки тривалості імпульсів передбачено використання інструмента Stopwatch у MPLAB X IDE.

Фактичні значення часу та кількості машинних циклів потрібно визначити під час симуляції.

### 5.5. Моделювання в Proteus VSM

Для дослідження сигналів необхідно створити електронну схему з мікроконтролером PIC16F84A та віртуальним осцилографом.

Вихід RB4 підключається до осцилографа для перевірки імпульсів, а RB0 використовується для дослідження програмного ШІМ.

## 7. Контрольні запитання

### 1. Що таке шпарність імпульсів?

Шпарність імпульсів — це відношення періоду повторення імпульсів до тривалості одного імпульсу високого рівня.

S = T / τ

де T — період сигналу, τ — тривалість імпульсу.

Шпарність є величиною, оберненою до коефіцієнта заповнення: S = 1 / D.

### 2. Для чого в програмі застосовується цикл?

Цикл використовується для багаторазового виконання певних команд. У програмах для мікроконтролерів цикл while(1) забезпечує безперервну роботу пристрою.

Для формування часових затримок можуть застосовуватися цикли з лічильником, які виконуються протягом заданого часу.

### 3. Яким чином можна організувати меандр?

Меандр — це періодичний прямокутний сигнал, у якому тривалість високого та низького рівнів однакова.

Для його формування потрібно почергово встановлювати на виході мікроконтролера логічні рівні 1 та 0 з однаковими часовими інтервалами.

Коефіцієнт заповнення меандра становить 50%, а шпарність дорівнює 2.

### 4. Яку максимально можливу частоту можна реалізувати програмним способом при використанні МК з частотою 4 МГц?

Для PIC16F84A з тактовою частотою 4 МГц тривалість одного машинного циклу становить 1 мкс.

Теоретична максимальна частота перемикання виходу за допомогою найкоротшого циклу команд становить приблизно 500 кГц, якщо один повний період потребує двох машинних циклів.

Фактична максимальна частота залежить від кількості команд, способу формування сигналу та програмної реалізації.

### 5. Як з використанням HI-TECH забезпечити виконання функцій, що реалізують часові затримки?

У компіляторі HI-TECH PICC для формування часових затримок використовуються функції delay(), delay_us() та delay_ms().

Для їх роботи необхідно підключити відповідні заголовкові файли та визначити тактову частоту мікроконтролера.

У сучасному компіляторі XC8 застосовуються функції __delay_us() та __delay_ms() з визначенням _XTAL_FREQ.

### 6. Для чого застосовується програма PROTEUS VSM?

Proteus VSM використовується для моделювання електронних схем і перевірки роботи мікроконтролерів без використання фізичного обладнання.

У програмі можна створювати електронні схеми, завантажувати HEX-файли, запускати симуляцію та досліджувати електричні сигнали за допомогою віртуальних вимірювальних приладів.

## 8. Висновок

Під час виконання лабораторної роботи №3 було розглянуто принципи формування часових інтервалів та генерації електричних імпульсів за допомогою мікроконтролера PIC16F84A.

Було підготовлено програми мовою C для генерації сигналів із цільовою частотою 5 кГц та коефіцієнтами заповнення 10% і 90%.

Також розроблено навчальний алгоритм програмної широтно-імпульсної модуляції з можливістю зміни коефіцієнта заповнення за допомогою двох кнопок.

Розглянуто призначення інструмента Stopwatch у MPLAB X IDE та віртуального осцилографа Proteus VSM для перевірки часових характеристик сигналів.

Отримані знання дозволяють краще зрозуміти принципи програмного формування імпульсів і використання ШІМ для керування електронними пристроями.

Фактичні результати компіляції, вимірювання часових інтервалів і моделювання необхідно підтвердити під час запуску програм у MPLAB X IDE та Proteus VSM.
