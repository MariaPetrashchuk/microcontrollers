
# Лабораторна робота №3

**Тема:** Формування часових інтервалів. Використання секундоміра MPLAB.

**Навчальна дисципліна:** Мікроконтролери та їх програмування

**Виконала:** Петращук Марія

## 1. Мета роботи

Навчитись застосовувати мікроконтролери для схемотехнічних рішень. Використовуючи принципову схему пристрою, скласти програму, що генеруватиме електричні коливання.

## 2. Завдання

1. Розробити програму генерації електричних коливань із використанням часових затримок.
2. Сформувати на виводі RB4 мікроконтролера PIC16F84A імпульси з частотою 5 кГц.
3. Розрахувати тривалість імпульсів для коефіцієнтів заповнення 10% і 90%.
4. Дослідити роботу програми в MPLAB X IDE за допомогою Simulator і секундоміра.
5. Створити електронну схему в Proteus VSM.
6. Перевірити форму сигналу за допомогою віртуального осцилографа.
7. Реалізувати програмне керування ШІМ на виводі RB0 за допомогою двох кнопок.
